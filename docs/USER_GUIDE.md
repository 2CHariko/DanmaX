# DanmaX 最终用户实操指南 (User Guide)

DanmaX 是一款 Windows平台下的原生高性能外挂弹幕工具，支持将弹幕透明悬浮在视频播放器、网页浏览器或整个桌面上。本指南将引导您快速上手使用 DanmaX。

---

## 1. 软件获取与运行

### 1.1 绿色便携特性
DanmaX 静态便携版（推荐）是一个完全绿色的可执行文件：
- **零外部安装依赖**：不需要额外安装 Qt、Python 或 VC++ 运行库，仅依赖 Windows 10/11 系统内置库及显卡驱动。
- **即开即用**：解压发布的压缩包后，直接双击运行 `DanmaX.exe` 即可启动。

### 1.2 便携目录文件结构
首次运行后，`DanmaX.exe` 会在同级目录下自动创建必要的数据与缓存文件夹：

```text
你的解压目录/
├── DanmaX.exe          # 主程序（静态单文件）
├── settings.ini         # 配置文件（纯 UTF-8，自带完整中文说明）
├── player-presets.json  # 外部播放器默认项和程序路径
├── recent-videos.json   # 媒体库最近播放、进度和弹幕来源引用
├── media/              # 媒体库专属匹配关联
├── app.log              # 运行日志（单文件 2 MiB 自动轮转）
└── cache/              # 运行缓存目录
    ├── danmaku/        # 在线搜索下载的弹幕缓存（长期保留，可离线使用）
    └── tmp/            # 进程临时缓存（关闭程序后可随时安全删除）
```

> **便携迁移技巧**：若需更换电脑或移动软件位置，只需将整个文件夹（或至少 `DanmaX.exe`、`settings.ini` 与 `cache/danmaku/`）一同移动即可无损保留所有偏好设置与已下载弹幕。

## 2. 界面与功能布局

DanmaX 界面采用原生 FluentWinUI3 风格，导航为首页、播放、媒体库、日志、设置、关于。

“播放”统一展示弹幕或番剧元信息，底部播放条跨页面常驻，提供播放／暂停、进度、选集、弹幕和播放器操作。独立模式暂停弹幕时钟，外部模式控制播放器；隐藏／卸载弹幕不等于暂停视频。“媒体库”负责打开视频和最近播放，打开后进入播放页。浏览和准备来源不打断当前任务，明确开始另一内容才交接。详见 [统一播放说明](NOW_PLAYING.md)。

## 3. 弹幕加载方式

### 拖入视频并自动播放（当前开发版本）

将一个本地视频拖入 DanmaX 主窗口任意区域（含侧栏、标题栏和页面留白），或点击播放页／媒体库的“打开视频”，均打开视频任务并进入播放页。当前提供 64 位 PotPlayer 和 VLC 3.x 预设，在“设置 → 外部播放器 → 管理播放器”设置默认项、自动发现、手动选择或直接输入程序路径；输入完成、保存和启动前会验证路径、EXE 格式和架构。多个安装位置需明确选择；名称、启动参数与同步规则由预设维护。修改保存后生效，取消丢弃。旧播放器配置不读取、不迁移。详见 [外部播放器配置](EXTERNAL_PLAYERS.md)。

有效视频拖入时，全窗口背景模糊并显示文件名及“松开以播放视频”。离开窗口、按 Escape 或松手后结束反馈；弹窗打开期间暂停接收视频拖放。软件渲染或高对比度环境使用主题纯色背景。模糊仅用于拖入期间的主窗口反馈，不作用于独立弹幕覆盖层。

PotPlayer 会等待并确认目标视频的真实媒体会话，然后自动匹配关联／缓存／在线弹幕并按当前进度显示，无需再点击“开始播放”。失败或有歧义时使用现有手动匹配弹窗。同名媒体无法靠 SMTC 确认完整路径时，需核对播放器画面后点击“使用当前视频”。路径验证通过不代表媒体同步已就绪。

选择 VLC 后，DanmaX 会启动独立受控窗口，通过本地接口确认完整视频路径并自动载入弹幕，无需安装 SMTC 插件或手填连接参数。后续打开复用同一受控实例；普通已启动的 VLC 窗口不会被接管。安装必须包含 Lua HTTP 组件，当前支持 VLC 3.x x64。连接断开后重新打开视频即可建立连接。

播放页“连接播放器与播放方式”中的“选择媒体会话”会自动发现支持的 VLC 进程。已连接实例可直接选择；灰色的“未建立同步连接”表示进程存在，但当前没有可用的 DanmaX 连接，请将 VLC 设为默认外部播放器后使用“打开视频”。列表不会自动接管普通 VLC，也不支持重启 DanmaX 后恢复上次的认证连接。

视频确认后才加入最近播放；有有效进度可继续观看或从头播放。恢复位置失败时保留原记录，可重试或按当前位置继续。视频任务连接不修改独立弹幕的绑定偏好，换 XML／卸载弹幕保留视频连接；卸载后显式重新匹配才恢复自动选源。播放器自行切换到未确认内容会清除旧弹幕并停止记录，请从媒体库重新打开。取消匹配或退出 DanmaX 不会关闭外部播放器。已保存的 EXE 路径失效时提示处理，不静默选用其他安装；PotPlayer 的多个实例或其他安装路径冲突也需先处理。

当前仅支持单个本地视频；文件夹、批量文件和网络 URL 不接受。同目录 XML 不会自动套用。直接操作播放器自身窗口时，需要该窗口已提供所绑定的媒体通道，不能自动接管普通 VLC 窗口。其他播放器须新增专属预设并完成适配验证后提供。

DanmaX 支持**本地 XML 加载**与**在线弹幕搜索**两种来源：

### 3.1 本地 XML

在播放页空闲时点击“打开弹幕”，或在底部“更多 → 独立播放弹幕 XML”选择文件，即可独立播放。已有任务使用“弹幕 → 更换弹幕 XML”；视频任务保留连接，独立任务保留所选模式和暂停意图，载入失败保留原任务。

需要先准备来源再跟随播放器时，从底部“播放器”展开来源与播放方式设置，选择本地 XML 并加载，然后点击“播放所选弹幕”。

> XML 清洗设备会修正非法 C0 控制字符，并将未定义颜色回退为白色。

### 3.2 在线搜索与缓存

底部“弹幕 → 搜索弹幕”打开搜索与分集选择；“选择缓存与来源”展开缓存列表。视频中的操作归属当前视频，其他情况下准备独立弹幕。已识别番剧的独立弹幕可使用底部“选集”切换分集；本地视频尚无剧集列表映射。

## 4. 播放模式与控制

### 4.1 跟随播放器

点击“连接播放器”，选择媒体会话和弹幕来源，再点击“播放所选弹幕”。弹幕跟随播放器位置、暂停和跳转；底部播放／暂停在后端支持时直接控制播放器，并等待真实状态读回。会话丢失时冻结弹幕，重连后重新对齐。

播放器前台限制仍由“设置 → 窗口行为”控制。主面板及所属对话框保留原有前台例外和层级规则。

### 4.2 独立播放

“打开弹幕”直接启动独立弹幕时间轴，也可在来源设置中选择“独立播放”后开始。底部播放／暂停和进度条控制弹幕；页面切换不打断任务。更换来源从新弹幕的零时刻开始，保留暂停意图。

视频模式仍由外部播放器显示画面。受控 VLC 支持底栏进度拖动；PotPlayer 暂时只读，精确续播未通过验收时不会显示恢复成功。

### 4.3 结束、隐藏与卸载

- “更多 → 结束本次播放”：结束当前弹幕任务和控制事务，不主动关闭或暂停外部视频；已准备的独立弹幕可重新开始。
- “弹幕 → 显示弹幕”：仅改变文字显示，视频／时间轴继续运行。
- “弹幕 → 卸载弹幕”：清除当前弹幕；视频任务保留视频连接，并暂停自动匹配，显式重新匹配后恢复。

### 4.4 顶部快捷工具栏

- 覆盖层允许显示时，将鼠标移到所选屏幕顶部、与主工具栏同宽的感应带，工具栏会展开。感应带高度为 10 逻辑单位，宽度随播放模式、字号和窄屏布局更新，不计进度／不透明度浮层。
- 未固定时，离开工具栏及已打开浮层的整体区域 1 秒后完全隐藏，不显示把手；再次移到顶部中央即可唤出。
- 滑块拖动和按钮按下期间保持显示。固定工具栏后，离开只关闭浮层；取消固定后恢复自动隐藏。
- 主面板前台时，工具栏仍按固定／自动隐藏／顶部感应规则显示，已打开的浮层和进度预览保留。所属对话框位于工具栏上方，模态对话框打开期间遵守原有输入限制。只有播放停止或覆盖层显示条件不满足时，工具栏、浮层与提示气泡立即隐藏，取消未提交的进度拖动并停用顶部感应；保留固定状态。隐藏弹幕文字的按钮只控制文字显示。
- 独立模式提供暂停／继续、停止及进度浮层；跟随模式提供退出覆盖层和同步偏移，正值提前、负值延后。两种浮层互斥，离开后关闭；停止或显示许可撤销时取消尚未提交的进度拖动。
- 工具栏宽度受所选屏幕约束，窄屏按功能组换行。工具栏停止后完全隐藏，再次开始需使用主面板。

## 5. 外观与性能调优建议

设置与播放页的普通下拉框展开时，会在原字段位置显示当前选中项，并暂时隐藏原文字和箭头；关闭后恢复。候选较多时可滚动，也支持方向键、Enter 确认、Escape 取消和 F4／Alt+Down 开关。可输入的下拉框保留编辑区。菜单和下拉使用随浅深主题变化的底色、细描边和柔和阴影，不支持阴影时自动简化；当前不提供真实 Acrylic 模糊材质。

进入“设置”页面，您可以根据个人喜好与硬件配置进行微调：

- **弹幕字体**：支持系统字体智能下拉选择与前缀补全。推荐使用笔画清晰的无衬线字体（如 `Microsoft YaHei UI`, `Segoe UI` 等）。
- **基准字号与描边**：默认基准字号为 24px，文字描边为 1px。高分辨率屏（2K/4K）可适当调大字号。
- **允许弹幕重叠**：默认关闭。关闭时当所有轨道均有弹幕正在流动时，超额新弹幕将礼貌避让或丢弃；开启后在轨道占满时允许局部重叠显示。
- **文字缓存 (Texture Budget)**：
  - 默认开启**自动按需模式**，系统将根据活跃弹幕量自适应扩缩显存（64 MiB ~ 512 MiB）。
  - 若显卡显存充裕且追求极致 165Hz/240Hz 超高刷，可开启自动模式或调大容量上限；低配集成显卡设备亦可调低上限，系统将自动平滑降级至矢量文字渲染。
- **窗口置顶**：仅提供“不置顶”和“置顶”，默认置顶。开启后通过窗口事件和周期检查自动恢复弹幕与工具栏层级，不抢占播放器焦点；不能保证覆盖独占全屏或系统特殊窗口。旧配置中的策略 2/3 自动合并为置顶。
- **调试信息**：开启后在所选屏幕角落显示紧凑面板，默认宽度 320 逻辑单位。媒体标题最多两行，超出部分省略；窄屏下性能指标可换行。显示省略不影响完整媒体标题和诊断报告。

## 6. 常见问题解答 (FAQ)

### Q1: 为什么点击“开始播放”后屏幕上没有任何弹幕？
- **排查 1**：请检查是否已点击“加载弹幕”按钮且弹幕数量大于 0。
- **排查 2**：检查当前视频/时间轴位置。如果第一条弹幕出现在第 60 秒，而当前时间为 0 秒，弹幕尚未到达显示时刻。
- **排查 3**：如果使用的是多显示器，请在“设置 → 窗口行为”中检查“显示器”索引是否选对了正在播放视频的屏幕。

### Q2: 为什么在“关联媒体会话”下拉框中找不到我的播放器？
- Windows SMTC 会话由 Windows 系统统一管理。请确认：
  1. 播放器支持 Windows 系统媒体控制（例如 Chrome/Edge 开启了 Media Session，PotPlayer 开启了系统媒体键集成）。
  2. 播放器当前**正在播放**或**处于活动暂停**状态，未彻底关闭媒体文件。

### Q3: 弹幕覆盖层会阻碍我的鼠标操作吗？
- **完全不会**。DanmaX 的弹幕覆盖层原生应用了 Windows `WS_EX_TRANSPARENT` 与 `WS_EX_NOACTIVATE` 属性，属于完全鼠标穿透型透明窗口，点击、双击、拖动、滚轮等操作会直接穿透作用于其底层的播放器或桌面。

### Q4: 提示某个在线搜索服务器连接超时或失败？
- 在线弹幕依赖第三方公网 API。若某个节点暂时不可用，您可以在“设置 → 在线弹幕”中调整服务器列表顺序，或添加其他可用的弹弹play 兼容镜像地址。DanmaX 会按照列表从上到下自动顺序重试回退。

### Q5: 如何彻底重置所有设置？
- 在“设置 → 配置与关于”区域，点击 **“恢复默认设置”**，或直接关闭程序后删除 `settings.ini` 文件，下次启动时将自动重新生成标准默认配置。
