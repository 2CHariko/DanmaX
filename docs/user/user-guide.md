# DanmaX 用户指南

本指南帮助你快速安装、运行并日常使用 DanmaX 进行本地视频弹幕同步、独立弹幕播放、在线检索及外观与性能调优。

## 1. 获取与运行

### 1.1 绿色便携特性

DanmaX 静态便携版（推荐）将应用与运行时封装为单个可执行文件：

- **无需安装外部依赖**：不需要手动安装 Qt、Python 或 VC++ 运行库，仅依赖 Windows 10/11 系统组件与显卡驱动。
- **开箱即用**：将发布包解压至可写目录后，直接双击 `DanmaX.exe` 即可启动。

### 1.2 便携目录结构

首次运行后，`DanmaX.exe` 会在同级目录自动生成配置、日志与缓存文件：

```text
DanmaX/
├── DanmaX.exe           # 主程序（静态单文件）
├── settings.ini         # 主配置文件（UTF-8，含完整中文注释）
├── player-presets.json  # 外部播放器默认预设与程序路径
├── recent-videos.json   # 最近播放记录、续播进度与弹幕来源引用
├── media/               # 媒体库视频与弹幕匹配关联记录
├── app.log              # 运行日志（单文件上限 2 MiB 并自动轮转）
└── cache/               # 缓存目录
    ├── danmaku/         # 已下载的在线弹幕缓存（长期保留，支持离线复用）
    ├── metadata/        # 番剧元信息 JSON 与封面缓存
    └── tmp/             # 进程临时目录（退出程序后可安全清理）
```

> [!TIP]
> 迁移至新设备时，只需将整个目录（或至少 `DanmaX.exe`、`settings.ini`、`player-presets.json` 与 `cache/danmaku/`）一同复制，即可完整保留偏好设置与离线弹幕。

## 2. 界面导航与播放中心

主窗口采用 FluentWinUI3 设计语言，侧栏分为上部核心页面（**首页**、**播放**、**媒体库**）与下部辅助页面（**日志**、**关于**、**设置**），底部固定全宽播放控制条。

- **播放**：展示当前任务的弹幕或番剧信息；底部播放条跨页面常驻，提供播放/暂停、进度定位、选集、弹幕与播放器菜单。
- **媒体库**：集中打开本地视频、查看与续播最近视频。浏览或准备来源时不会中断当前播放，仅在你显式启动新内容时交接任务。

详细信息请参阅 [播放中心](../architecture/now-playing.md) 与 [双任务工作流](../architecture/dual-workflows.md)。

## 3. 加载视频与弹幕

DanmaX 支持**视频同步**和**独立弹幕**两种互斥任务模式。

### 3.1 打开本地视频（同步模式）

将单个本地视频拖入主窗口任意区域，或在 **播放** / **媒体库** 页面点击 **打开视频**，DanmaX 将按以下流程工作：

1. **校验默认播放器**：目前支持 **PotPlayer x64** 与 **VLC 3.x x64** 预设（开发构建另可选内置 libVLC）。你可以在 **设置 → 外部播放器 → 管理播放器** 中自动发现、手动选择或输入程序路径。
2. **启动受控实例**：
   - **PotPlayer**：通过 `/new` 启动独立进程并通过原生窗口消息同步位置与状态。
   - **VLC**：启动独立受控实例并通过本地 HTTP 接口确认完整视频路径（要求安装目录包含完整的 Lua HTTP 组件）。
3. **恢复进度与自动匹配弹幕**：视频确认后写入 `recent-videos.json` 并恢复有效历史进度，随后自动匹配关联、本地缓存或在线弹幕。

> [!NOTE]
> DanmaX 只接受单个本地视频文件，不支持拖入文件夹、批量文件或网络 URL，也不会自动套用同目录 XML。退出应用或结束任务时，仅请求关闭本次由 DanmaX 启动的受控播放器实例，不会影响你原有的其他播放器窗口。

### 3.2 独立播放弹幕 XML（无播放器模式）

当你需要脱离视频播放器单独浏览或调试弹幕时：

- 在底部操作栏选择 **更多 → 独立播放弹幕 XML**，或通过 **首页 / 弹幕菜单** 选择在线分集或缓存来源。
- 独立模式使用本地单调时钟驱动，播放/暂停与进度拖动仅作用于弹幕时间轴。
- XML 解析器会自动清洗非法 C0 控制字符，并将缺失颜色字段回退为白色。

> [!NOTE]
> 在尚无活动任务时，打开搜索或缓存列表不会隐式启动独立播放；请先明确打开视频或启动独立 XML。

### 3.3 混合匹配与手动匹配弹窗

视频就绪并恢复位置后，DanmaX 采用规则与 Anitomy 混合解析视频文件名并按以下优先级匹配弹幕：

1. **唯一有效本地缓存**：在离线或在线服务列表为空时仍可命中；同剧集在兼容服务中的缓存副本不重复载入。
2. **已确认历史关联**：复用 `media/media-associations.json`（最多 512 条、512 KiB 上限）中保存的精确摘要或番名/分集映射。
3. **在线检索唯一命中**：仅在规范化番名与分集唯一匹配时自动载入，不会把搜索结果第一条盲目作为匹配项。
4. **手动匹配弹幕弹窗**：当无法解析、无匹配或存在歧义时，自动请求暂停正在播放的视频并弹出“手动匹配弹幕”窗口（外部播放器使用独立置顶窗口，内置播放器使用弹窗），支持复制媒体标题、在线搜索选集或选择本地 XML。提交或取消后，仅在确认该次暂停由匹配流程发起时请求恢复播放。

## 4. 播放控制与快捷工具栏

### 4.1 底部播放条与任务切换

- **弹幕菜单**：控制显示/隐藏弹幕、加载/更换本地 XML、搜索在线弹幕、选择缓存、重新匹配（视频模式）以及卸载弹幕。卸载弹幕会保留当前视频连接并暂停自动匹配，直到你显式点击 **重新匹配**。
- **播放器菜单**：在视频任务中调整预设设置。
- **结束本次播放**：通过 **更多 → 结束本次播放** 结束当前任务并请求正常关闭受控播放器实例。

### 4.2 顶部快捷悬浮工具栏

当弹幕覆盖层处于允许显示状态时，将鼠标移至目标屏幕顶部中央（高度 10 逻辑单位、宽度与工具栏主条一致的感应带）即可唤出快捷悬浮工具栏：

- **自动隐藏与固定**：未固定时，鼠标移出工具栏及已展开浮层区域 1 秒后自动隐藏；点击固定按钮可保持常显。
- **模式差异**：
  - **独立模式**：提供暂停/继续、停止、前后 5 秒跳转与进度拖动浮层。
  - **跟随模式**：提供退出覆盖层与时间轴同步偏移调节（正值提前、负值延后），不直接操控播放器进程。
- **互斥与取消**：进度浮层与不透明度浮层互斥打开；停止播放或覆盖层许可被撤销时，立即隐藏工具栏并取消未提交的拖动草稿。

## 5. 外观、缓存与性能调优

### 5.1 弹幕显示与性能建议

进入 **设置** 页面可实时调整并保存参数（详见 [配置文件参考](configuration.md)）：

- **弹幕字体**：支持系统字体下拉与前缀检索，推荐使用笔画清晰的等宽或无衬线字体（如 `Microsoft YaHei UI`、`Segoe UI`）。
- **基准字号与描边**：默认基准字号 `24`、描边 `1`；2K/4K 高分屏可适当提高字号。
- **允许弹幕重叠**：默认关闭，防止弹幕密集时文字重叠影响阅读；高密度弹幕场景可按需开启。
- **文字缓存预算**：默认启用自适应模式（64–512 MiB 按需扩缩），显存受限设备可切换为手动较低上限；超出部分自动平滑回退为矢量文本节点，不会丢失弹幕。

### 5.2 番剧元信息与封面缓存

首页推荐、周历与详情缓存位于 `cache/metadata/`：

- **离线优先与冷却**：日历/分集有效期 6 小时、详情 24 小时、搜索 1 小时、封面 30 天；同一资源请求失败后冷却 5 分钟，手动刷新可跳过冷却。
- **磁盘上限**：JSON 上限 64 MiB、封面上限 512 MiB，按最近使用时间自动淘汰；在 **设置 → 番剧元信息缓存** 中可查看占用并一键清空（不会影响已下载的弹幕缓存与用户配置）。

## 6. 常见问题排查

### 为什么开始播放后屏幕上没有弹幕？

1. 确认已加载有效的弹幕来源且弹幕总数大于 `0`。
2. 检查当前播放时间位置：若首条弹幕位于第 60 秒而当前位于 0 秒，需等待或定位到对应时间。
3. 在多显示器环境中，前往 **设置 → 窗口行为** 核对 **显示器** 索引是否指向视频播放所在屏幕。

### 为什么无法连接已打开的外部播放器？

DanmaX 不再通过枚举进程名或窗口标题接管你自行打开的普通播放器窗口。请将播放器设在 **设置 → 外部播放器** 中后，通过 DanmaX 的 **打开视频** 或拖放视频文件来启动受控实例。

### 弹幕覆盖层会遮挡鼠标点击或拖放操作吗？

不会。弹幕覆盖层在 Windows 上启用了 `WS_EX_TRANSPARENT` 与 `WS_EX_NOACTIVATE` 属性，所有鼠标点击、双击、拖动与滚轮事件均会直接穿透到底层播放器或桌面。

### 提示在线弹幕服务器连接超时或失败怎么办？

在线检索依赖第三方兼容弹弹play 协议的公共服务。你可以在 **设置 → 在线弹幕** 中调整服务器列表顺序或添加其他可用镜像节点；DanmaX 会按顺序自动回退重试。

### 如何重置所有应用设置？

在 **设置 → 配置与关于** 中点击 **恢复默认设置**，或退出全部 DanmaX 进程后删除同目录下的 `settings.ini` 并重启程序。
