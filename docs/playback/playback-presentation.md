# 播放底栏与内置观看布局

本文档定义统一底部播放控制条与开发版内置视频观看布局的交互规范、全屏迁移机制及实机验证边界。

> [!NOTE]
> 全屏与隐藏侧栏的观看布局仅作用于开发版内置视频任务；外部播放器（PotPlayer / VLC）与独立弹幕任务保持常规导航和原有窗口控制方式。

## 1. 界面布局与行为规范

- **统一底栏布局**：左侧仅显示标题与简短状态（无缩略图）；进度条独占上行（超过 1 小时采用 `h:mm:ss`）；下行主控按钮居中对齐整个窗口，两侧分别为等宽的 **后退 10 秒** 与 **前进 30 秒**；右侧集中放置 **弹幕**、**播放器**、**全屏** 与 **更多** 菜单。窄窗按优先级依次隐藏次要状态、收纳播放器菜单至“更多”、缩短或隐藏标题；极端文字放大时辅助操作折行并保持命中尺寸。
- **内置观看布局**：仅当位于 **播放** 页且当前为内置视频任务时隐藏侧栏、分割线及周围页面内边距。窗口模式下保持紧凑标题栏（含返回按钮与 QWindowKit 窗口按钮）与固定底栏；返回浏览页后媒体继续后台运行，视频与弹幕隐藏且不补发隐藏期弹幕。
- **全屏呈现**：通过底栏按钮或 `F11` 切换应用自身全屏；`Escape` 优先关闭已打开菜单或弹窗，随后退出全屏。全屏期间视频几何不随底栏显隐跳变：鼠标、触摸或键盘操作唤出底栏，播放中空闲 3 秒自动隐藏（暂停、加载、错误、定位等待、拖动、键盘焦点或弹窗打开时常显）；失去前台或最小化时隐藏控制窗，收起后不留透明输入拦截层。
- **局部深色主题**：观看页标题栏、底栏及其菜单通过 `Ui` 语义颜色与公开 `palette` 固定采用深色呈现，不更改全局主题偏好；其他页面与来源弹窗保持用户主题。

## 2. 实现边界

- `PlaybackPresentationController` 在 GUI 线程管理呈现状态、窗口恢复与全屏期 50 ms 指针/前台感知（不参与媒体采样或弹幕计时）。
- 窗口模式下底栏位于主场景，全屏时将同一底栏 `Item` 迁移至主窗拥有的独立 `QQuickWindow`，维持“业务弹窗 > 控制条 > 视频与弹幕”层级，不采用桌面全局置顶。切换宿主前关闭菜单并取消未提交拖动草稿；视频 HWND 与 `SeekController` 事务保持连续。
- `NowPlayingModel::seekRelative` 在当前预览目标上累计并夹取边界，仍走统一 `SeekController`（独立弹幕走本地时钟）。
