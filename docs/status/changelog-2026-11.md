## 弹幕准备暂停与外部手动匹配窗（2026-11-13）

- Debug 部署启动访问冲突发生在加载 `Main.qml` 时，空数据目录同样复现。独立匹配窗改为首次需要时创建；旧 Debug 增量产物仍崩溃，完整重建并重新部署后原运行目录的启动和增量冒烟均退出 0。主窗口关闭后显式退出事件循环；用部署后的 Debug 和真实 PotPlayer 验证独立窗出现、关闭主窗口后应用退出 0。未清空用户配置或历史。记录见 `out/validation/debug-startup-crash/`。
- 开片自动准备和重匹配先请求暂停，实际提交弹幕或取消后按同一事务恢复。外部匹配窗可在主窗口最小化时独立显示，和顶部工具栏共用 Windows 层级管理；切走撤销匹配窗临时置顶。内置播放器保留原有弹窗。
- 内置 Release 应用构建与冒烟通过，相关 CTest 8/8。原生窗口与外部播放器专项 8 passed（含初始化／清理），以无音轨 AVI 实测 PotPlayer 和外部 VLC 的独立弹窗、确认暂停、XML 提交恢复和受控实例退出。层级测试使用真实 HWND 与注入的播放器前台判定，覆盖工具栏、子窗口、切走撤销和关闭置顶。内置全屏隔离复测 3 passed；组合运行曾出现键盘焦点断言失败。150% 模拟缩放加放大文字专项 5 passed。记录见 `out/validation/matching-window/`。
- 补测复现了换片时关闭 Windows 原生 XML 选择器导致的 Qt 崩溃。匹配界面改用 Qt Quick 自带选择器；原生 Windows 平台的标准及 150% 模拟缩放专项分别 3 passed，覆盖浅深主题下的留白滚轮和换片关闭选择器。外部播放器全屏下的物理操作、真实混合 DPI／跨屏和任务栏闪烁的人工验证尚未完成。

## 拖动卡顿与延迟采样误重置（2026-11-13）

- 跟随播放在采样时刻比较播放器读数和预测位置，再推进显示时钟；晚到的暂停或倍速变化只修正尚未绘制的运动。真实跳转、内容交接和重连仍显式重置活动弹幕，重置以原始落点为准，定位事务仍使用原始读数。领域及控制器回归覆盖 300 ms／1 秒晚到、350 ms GUI 排队、暂停／恢复、倍速和前后跳转。
- 隔离试验比较了提前请求下一帧与原调度。Windows 11、Ryzen 5 5600／RTX 4070、1920×1080、DPR 1、180 Hz，独立 XML 滚动弹幕，Debug 结束时约 158–179 条、Release 约 190 条；脚本按相同轨迹移动／缩放主 HWND。Debug 原生移动段 P95 由 63.28 降至 39.92 ms，但 Release 整轮移动 P95 由 9.66 增至 16.16 ms，缩放由 14.93 增至 20.51 ms。未保留调度候选，未将试验视为实际鼠标拖动或光学帧率验收。记录位于 `out/analysis/drag-optimization/`。
- 最终 Debug 与内置 Release 定向 CTest 各 3/3，两个隔离运行目录启动冒烟通过。两种构建的真实 PotPlayer 和外部 VLC 专项均通过（无音轨 AVI）；Release PotPlayer 首轮发现测试夹具默认选中了内置播放器，夹具改为显式选择 PotPlayer 后复验通过。真实播放器专项验证播放契约，不代替人工拖动中的视觉复测。

## 弹幕覆盖窗层级闪烁修复（2026-11-13）

- 原生探针确认旧的整组重排会先把弹幕窗抬到主面板之上，再恢复目标顺序。现在保留已正确的层级，需移动弹幕窗时直接放在同置顶组的主面板或工具栏下方；工具栏及浮层的显隐在原生可见性更新后重新检查。内置视频的窗口跟随不参与这条置顶路径。
- 内置 Release 构建、工具栏 CTest、原生窗口顺序与外部置顶竞争恢复专项通过。新增原生回归验证收起工具栏时层级正确便不重排，再次显示仍在主面板上方。原生鼠标专项因 Windows 未授予测试窗口前台而跳过；实际重叠时的画面闪烁待人工复测。

## 播放基线复验与默认便携包（2026-11-13）

- 重新构建 `c3a01ae` 的默认静态 Release 与内置 Release，完整 CTest 分别 23/23 和 25/25 通过。真实 PotPlayer 和外部 VLC 使用无音轨 AVI，各 3 项通过、0 失败／跳过（含初始化／清理）。原生界面的独立 XML 菜单专项 3 项通过，覆盖选择、取消、播放／暂停及任务隔离。
- 内置 Release 用同一 1080p HEVC 的无音轨副本做前台交互，实际拖动标题栏、F11 进入全屏、Escape 退出、点击返回首页再回观看页，视频继续播放。240 秒结束，237 个播放采样、7 项状态检查通过、退出 0；原生移动循环进入／退出各一次，17 次位置事件处理后最大矩形差 0px，原生失败 0。两个独立 GPU 表面仍不保证逐帧同步呈现。
- 同一个内置 EXE（SHA-256 `96FD584446566D87A3618BD831DAAEDBF328FC86672F00F50F6597E3C4DBF092`）完成 1920 秒实播长测：1846 个全屏采样、1888 个播放采样，12 项检查全过，视频 HWND／连接保持不变，0 QML 引擎警告、无视频任务错误，脚本和应用均退出 0。1920×1080、DPR 1、180 Hz 下记录显示 45666 帧、丢 17 帧、音频缓冲 0；图形与原生退出警告仍见日志。含计划暂停与定位、同机运行其他验证，不作为独占前台性能或零掉帧结论。
