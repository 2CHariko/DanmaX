# 配置文件说明

程序只读写 `settings.ini`，编码为 UTF-8。静态便携版默认放在 EXE 同级目录；开发运行位置由 `run.ps1` 指定。首次运行自动创建完整配置，分组和所有字段均带中文说明，包括用途、默认值、单位、允许范围和可选值。默认模板见 [settings.example.ini](settings.example.ini)。

这是破坏性格式变更：不读取或迁移旧 `settings.json`、旧版 `config.ini`，设置页不再提供旧 INI 导入。旧文件不会被删除；新版本从新配置或默认值开始。

界面设置即时生效并保存，数值输入合并 200 毫秒后写盘，退出时刷新待保存修改。手动编辑前应退出所有实例，保存后重新启动；程序不会监视外部修改。每次程序保存都重建自带中文说明和所有已知字段，不保留用户额外注释、未知字段或自定义顺序。多实例写入尚无协调，避免同时修改同一配置。

## 手工编辑规则

- 保留 `[Meta]` 下的 `formatVersion=1`；未知版本和无版本配置不迁移。
- 布尔值推荐 `true` / `false`，读取也接受 `1` / `0` 和大小写形式；不接受 `yes` / `no`。
- 数值使用英文句点，不能写单位、千位分隔符或小数逗号。范围和整数要求见各字段注释。
- 字符串保留双引号，尤其是包含逗号、分号、前后空格的路径。中文直接写入；推荐正斜杠路径，例如 `lastFile="D:/弹幕/示例.xml"`。
- 反斜杠用 `\\`，字符串内双引号用 `\"`，换行用 `\n`。字符串开头的 `@` 写为 `@@`，遵循 Qt INI 转义规则。
- 缺少已知字段时用默认值；非法字段用默认值并显示错误，其余有效字段保留。损坏语法、非 UTF-8、超过 1 MiB 或版本无效时，整份配置使用默认值。

示例片段如下（完整文件还包括其他分组和字段）：

```ini
[Meta]
; 格式版本，不自动迁移其他版本。
formatVersion=1

[Appearance]
; 应用主题：system=跟随系统，light=浅色，dark=深色。
theme="system"

[Danmaku]
; 滚动弹幕速度，单位：逻辑像素/秒；整数 30～1500。
speed=180
; 顶部、底部固定弹幕显示时长，单位：秒；范围：1～30。
fixedSeconds=5
; 轨道已满时是否允许重叠。
overlap=false

[Playback]
; 最近加载 XML 的路径；启动不自动加载或播放。
lastFile="D:/弹幕/示例.xml"
```

## 系统字体选择

设置页“弹幕字体”自动列出 Qt 检测到的已安装字体家族，按名称排序并排除内部私有字体。可从下拉列表选择，或输入名称前缀自动补全；也可手动输入未列出的名称，按 Enter 或移开焦点确认，空输入恢复当前值。预览使用选定字体家族和与弹幕一致的半粗体，提供中文、英文与数字示例，不包含弹幕描边或动画。

仍保存原有 `fontFamily` 字符串，旧配置无需迁移。名称未在列表中找到时显示提示，字体别名也可能有效；缺失字形、emoji 和未安装字体由 Qt 回退，预览不保证每个字符都来自该字体。字体列表首次访问时枚举并缓存，接收 Qt 字体数据库变化通知后更新，不参与逐帧渲染。不主动安装、下载或打包系统字体。

字体下拉列表默认最多约 360 逻辑像素高（随界面文字缩放），根据窗口上下可用空间缩短或向上展开。列表过长时显示可拖动的垂直滚动条，选项文字为滚动条留出空间；展开后保持当前项完整可见，方向键选择、Enter 确认、Esc 关闭。

## 文字图片预算

设置页“文字缓存”可即时选择自动或手动模式，并调整容量；INI 对应新增 `[Rendering]` 分组，旧的有效格式版本 1 配置缺少这两项时使用默认值，不需要迁移。

```ini
[Rendering]
textureBudgetAuto=true
textureBudgetMiB=512
```

- `textureBudgetAuto`：默认 `true`。按当前活动文字的字体、字号、颜色、描边和实际 DPR 去重估算需求，排除尺寸/单张上传量超限的图片。自动从最多 64 MiB 起步，按两倍档位增长，保留 25% 需求余量；持续较低需求 10 秒后收缩，暂停时不为预算调整持续绘制。最后一条退场或停止会直接释放项目图片资源。
- `textureBudgetMiB`：整数 32–1024，默认 512。自动模式的增长上限，手动模式的固定预算；不是预分配容量。调低立即在渲染线程释放超额图片，保留活动弹幕及其 ID、位置、寿命和覆盖顺序，不重新读取 XML。
- 每帧估算新增 4 MiB 和累计准备 2 ms 的限制独立保留；单条准备可超过时间阈值。超出容量、尺寸（8192 px）、单张上传量或尚未准备的弹幕仍用 Qt 文字绘制。
- 预算只约束图片内容估算，不包括 Qt 图集、字形缓存和驱动资源，不是进程内存或真实显存硬上限。自动模式按文字需求调整，当前不查询系统显存压力。减少预算后 Qt/驱动可能保留通用缓存，停止的项目资源清理行为不变。
- 调试层显示图片内容占用、当前预算、总回退与容量回退；JSON 报告另含需求和准备/尺寸/分配回退原因。图片覆盖率、预算和实际帧率应一起判断。

## 滚动弹幕的底部边界

最大轨道数是上限，不会强制将屏幕均分为指定行数。滚动轨道按字体、描边和额外行距计算行高，屏幕容纳数向上取整；最后一行允许部分超出覆盖窗，由渲染层裁剪。可用行数仍受用户轨道上限约束。顶部/底部固定弹幕保留完整显示及边缘锚定规则，并与滚动弹幕共用碰撞区域。字体更大、行距更宽时仍会减少可用行数。

## 保存和恢复

正常保存使用 Qt `QSaveFile`，临时文件位于配置所在目录，提交成功后才替换原文件。读取损坏或非法配置不会立即覆盖；第一次界面保存、恢复默认值或重试保存前，先将原始字节复制到 `settings.ini.backup-<UTC 时间戳>`。备份失败时不覆盖原文件，界面提示错误；可修复目录权限或空间后重试。

目录必须可写。便携版不静默将配置移到 AppData，也不会自动删除旧配置或备份。移动 EXE 时携带 `settings.ini` 即可保留设置；若需要保留已下载弹幕，另携带 `cache/danmaku/`。其他可重建缓存可在所有实例退出后删除。

## 在线弹幕与长期缓存

```ini
[Online]
danmakuServers="[\"https://danmaku-api.152468.xyz\"]"
```

在“设置 → 在线弹幕”填写允许匿名访问的弹弹play兼容服务基础地址，例如 `https://example.com/prefix`（仅格式示例，不是可用服务）。支持 HTTP/HTTPS、端口和路径前缀；不要追加 `/api/v2`、查询参数、片段或账号密码。默认包含 https://danmaku-api.152468.xyz，启动不联网。地址列表可添加、编辑、删除和上下调整顺序，完成编辑后即时保存；地址规范化后拒绝重复。运行时为字符串列表，INI 为带转义的 JSON 数组字符串；空列表写作 danmakuServers="[]"，重启保持为空。旧 danmakuServer 字段不读取、不迁移；缺少新字段时使用默认列表，恢复默认也恢复内置地址。本版本不提供弹弹play账号登录或官方应用签名；401/403 提示需要认证，不能使用凭据占位值绕过。

播放页“在线搜索”依次搜索动画、选择动画与剧集，下载成功后保存并载入弹幕，仍需点击同步播放或独立播放。默认按配置顺序查找有效缓存，全部未命中再联网；“重新下载”强制联网；下载失败或取消保留当前播放和旧缓存。保存失败仍可载入已解析内容，界面提示“已载入但缓存失败”。新来源成功载入才停止旧播放并重置时间轴。

“已缓存”可筛选、离线载入和删除下载的弹幕，不收录本地 XML。缓存长期保留，不自动过期或清理。删除不卸载内存中已载入的弹幕；缓存列表刷新与 JSON 解析在后台进行。损坏/未知版本显示不可载入，可手动删除。

缓存位于应用缓存根的 `danmaku/`：静态便携版默认 EXE 旁 `cache/danmaku/`，开发运行在脚本指定的项目内 QML 缓存根下；`--cache-dir` 同时指定应用缓存根。缓存键包含规范化服务器地址、剧集 ID、`withRelated=true&chConvert=0`，不同来源隔离。每条是版本 1 的独立 JSON，使用 QSaveFile 原子替换；载入缓存不依赖当前服务器设置。

在线响应限 64 MiB，原始弹幕限 100 万条，规范化缓存限 128 MiB。每个地址单次请求超时 30 秒。搜索、剧集查询和下载都从首个地址串行尝试，每个地址最多一次；网络、HTTP、认证、格式、业务错误或无可用结果时回退，首份有效结果即停止，不合并结果。所有地址须共享弹弹play动画/剧集 ID。全部失败按地址列出原因；取消、新操作和修改列表终止整个回退链并废弃旧结果。缓存写入失败不切换服务，缓存元数据记录实际提供弹幕的地址。按 XML 的边界校验时间、文字和颜色，过滤高级/反向模式，规范字号 25，按时间稳定排序并精确去重。首版不做简繁转换、多轨叠加、SMTC 自动匹配或视频文件哈希识别。
