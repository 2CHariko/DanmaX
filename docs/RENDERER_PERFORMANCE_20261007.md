# 600 条真实文字渲染优化

默认改为整条文字图片缓存，保留 Qt 文字节点作为容量/尺寸回退和环境变量对照路径。该结果替代此前未完成渐进转换的图片实验结论；不推断 2000 条弹幕、其他硬件或长期场景的帧率。

## 改动与原因

原路径的 1 px Outline 在 Qt 内部分成描边及填充字形层；多种颜色又限制文字材质合批。较粗描边还需要应用创建 8 个偏移文字节点。整条文字图片将颜色、字形和描边合成一次，后续只更新矩形位置，允许 Qt 自己管理图集，不改变透明覆盖顺序。

此前图片路径超过首帧上传预算后不再重试，大量对象一直回退文字。现已分帧继续转换，旧对象先退场释放预算；相同字体/内容/颜色/描边/DPR 共享资源。图片只栅格化一次，用透明度遮罩合成黑色描边，彩色 emoji 不再形成偏移彩色副本。

内容纹理估算上限 64 MiB，每帧新增估算上限 4 MiB，累计栅格化及纹理准备达到 2 ms 后推迟新项；单条准备可能超过时间阈值，也不代表 GPU 上传耗时上限。大于 8192 px 或超过容量的图片回退 Qt 文字。指标不包括 Qt 图集、字形缓存和驱动开销。暂停不为填充缓存持续请求帧；停止释放项目缓存、快照和绘制资源。图片抗锯齿及描边与旧 Qt Outline 不保证像素一致。

## 对照环境与方法

- Windows 11，Qt 6.11.0，Static Release，D3D11，threaded 渲染循环。
- 2560×1440，DPR 1，显示器报告刷新率 165.002 Hz；Ryzen 5 5600、12 逻辑处理器；系统枚举 RTX 4070 及虚拟显示适配器，未从本轮报告提取具体 RHI 设备。
- 从用户 XML 密集区间只读提取 600 条原文，保留模式、源字号和颜色，时间统一为 0；153 滚动、130 底部、317 顶部，128 种颜色，平均约 54.85 字符。原文夹具只放在忽略的 `out/` 中，不提交。
- 微软雅黑 24 px，描边 1 px，透明度 0.85，速度 180，最多 60 轨道，允许重叠，控制面板及调试显示可见。固定寿命特意设为 30 秒，保证每轮结束仍有 600 条；不是默认寿命 5 秒。
- 两条路径各运行 3 轮、每轮 8 秒。最终对照单独执行，未同时运行构建/测试。GUI P95/P99 包含冷启动，更新率、呈现率和 CPU 取结束时实际采样区间，不是整段平均或光学 FPS。CPU 按逻辑处理器归一化，未测 GPU 执行时间。

运行：`scripts/compare-renderers.ps1 -Counts 600 -Rounds 3 -Seconds 8 -Xml out/validation/render-analysis-600/real-600/fixture.xml`。脚本以自身目录定位根目录，记录夹具与 EXE 摘要及环境，生成独立配置，不覆盖用户配置；传入其他 XML 时需同样在时间 0 投放指定数量。

## 验证边界

Static Release 11/11 CTest（33.42 秒），动态 Debug 11/11（81.02 秒）。新增 Qt Test 覆盖延期转换、ID/位置保留、重复内容共享、颜色/透明度、0/1/3 px 描边、超长文字回退、样式重建和卸载。原生 D3D11 的 threaded/basic × 默认/text 生命周期，以及 threaded/basic × DPR 1/2 默认渲染共 8/8 通过，原生检查还实际填充超过 60 MiB 且不越过 64 MiB 上限。报告与截图：`out/validation/renderer-native-optimized/`，中文、组合字符及 emoji 的原生截图已目视检查。offscreen 软件 Debug 只检查渐进增长与边界，不将其转换速度作为性能验收。

新增调试“呈现 Hz”来自覆盖窗 `frameSwapped`，“更新 Hz”来自 GUI 时间轴推进；两者均不是实际屏幕光学帧率。真实 SMTC、混合 DPI 跨屏移动、穿透、高对比度和长期压力等原有待验收项不扩大。
