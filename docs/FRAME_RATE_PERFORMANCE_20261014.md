# 帧率控制实测（2026-10-14）

本记录对应帧率控制第一版，功能定义见 [FRAME_RATE_CONTROL.md](FRAME_RATE_CONTROL.md)。呈现频率与间隔来自覆盖窗 frameSwapped 的 GUI 排队回调，是提交反馈代理，不是光学 FPS 或 GPU 执行时间。

后续优化改为记录发出线程时间戳，并补充 165 Hz / Debug 对照；见 [FRAME_RATE_OPTIMIZATION_20261014.md](FRAME_RATE_OPTIMIZATION_20261014.md)。下文保留第一版测量定义与结果。

## 环境与方法

- Windows 11 x64，Qt 6.11.0，`windows-static-release`，D3D11 / threaded 渲染循环。
- CPU：AMD Ryzen 5 5600，6 核 / 12 逻辑处理器。系统枚举 NVIDIA GeForce RTX 4070（驱动 32.0.16.1692），以及 GameViewer、Zako、MuMu 虚拟显示适配器；未单独确认本次 GPU 的执行时间或活动适配器。
- 覆盖窗显示器报告刷新率 **60 Hz**。100% 缩放为 2560×1440 逻辑尺寸 / DPR 1；`QT_SCALE_FACTOR=2` 为 1280×720 逻辑尺寸 / DPR 2，物理像素范围相同。后者是缩放模拟，不代表跨屏混合 DPI。
- 测试二进制 SHA-256：`238B21BD561E68A4ABDFA624CF104D0021A259867DC968B76EEFF15D68CF3B26`。
- 脚本使用隔离的配置、XML、缓存及报告目录。低负载每轮 15 秒；剔除播放位置前三秒后，对完整诊断窗口按时间加权，实际统计约 12 秒。P95 列为末五个诊断窗口各自 P95 的平均值，不是全程合并 P95。

```powershell
./scripts/validate-frame-rates.ps1
./scripts/validate-frame-rates.ps1 -Limits 60 -ScaleFactor 2 -StressSeconds 60
```

## 低负载限帧

场景：50 条顶部固定弹幕，字号 24、描边 1、固定寿命 30 秒，允许重叠，图片文字后端。自适应关闭。

| 上限设置 | DPR | 有效上限 Hz | 统计秒数 | 平均呈现 Hz | 末段间隔 P95 ms | ±5% 检查 |
|---|---:|---:|---:|---:|---:|---|
| 30 | 1 | 30 | 12.00 | 30.00 | 33.93 | 通过 |
| 60 | 1 | 60 | 11.97 | 60.00 | 17.21 | 通过 |
| 120 | 1 | 60 | 11.95 | 59.83 | 17.49 | 通过 |
| 47 | 1 | 47 | 11.95 | 46.86 | 33.75 | 通过 |
| 跟随显示器 | 1 | 60 | 11.98 | 59.92 | 33.54 | 通过 |
| 60 | 2 | 60 | 12.00 | 59.94 | 17.45 | 通过 |

47 Hz 在 60 Hz 显示器上包含不同垂直刷新间隔；跟随显示器这一轮平均频率达标，但末段 P95 约 33.54 ms，不能将平均值解释为每帧间隔恒定。120 的结果只验证受当前 60 Hz 屏幕约束，**没有验收实际 120 Hz 呈现**。

首轮 30 Hz 请求曾因其他窗口的 Qt 共享动画驱动出现约 60 Hz 呈现；增加公开 UpdateRequest 门控后重新执行以上完整对照。旧失败报告保留在 `out/validation/frame-rates-20261014-055129-466/`，不计为当前通过记录。

## 自适应压力对照

同一组内使用相同 XML：初始 2000 条，随后每秒 200 条持续入场，滚动 / 顶部 / 底部轮换，独立长中文 / English 文本，字号 48、描边 4、固定寿命 5 秒，最多 60 轨、允许重叠。用户容量 2000，底线 500，上限和目标填写 1000，有效值均为当前屏幕的 60 Hz。缓存预算沿用自动设置，末态纹理预算 512 MiB；自适应不改字体、描边或缓存容量。100% 每轮 45 秒，200% 每轮 60 秒。

| DPR / 自适应 | 全统计平均 Hz | 末五窗口平均 Hz | 末段 P95 ms | 最终在屏 / 入场额度 | 自适应跳过 | 末态 |
|---|---:|---:|---:|---|---:|---|
| 1 / 关闭 | 14.25 | 10.88 | 250.39 | 2000 / 2000 | 0 | 已关闭，目标未达成 |
| 1 / 开启 | 43.48 | 59.85 | 40.68 | 773 / 773 | 4967 | 已减量，末段平均达到目标 |
| 2 / 关闭 | 11.65 | 10.75 | 223.52 | 1860 / 2000 | 0 | 已关闭，目标未达成 |
| 2 / 开启 | 28.13 | 38.78 | 55.76 | 500 / 500 | 6836 | 已达到减量底线，目标未达成 |

“末段达到目标”只描述末五窗口平均频率；首次预热、判断和等待自然退场包含在全统计平均值中，不据此承诺整段稳定 60 Hz。脚本压力组 `passed=true` 表示有效数据采集完成；达标看独立的 `targetMet`，底线看 `floorReached` 与策略状态。DPR 2 开启组为 `targetMet=false`、`floorReached=true`、`state=unmet`。

| DPR / 自适应 | 末段 CPU % | 引擎 / 快照 / 场景图 CPU ms | 最终进程内存 MiB | 最终纹理估算 MiB | 最终文本回退节点 |
|---|---:|---|---:|---:|---:|
| 1 / 关闭 | 10.46 | 0.764 / 0.089 / 6.150 | 803.39 | 2.13 | 1996 |
| 1 / 开启 | 7.27 | 0.087 / 0.035 / 3.148 | 493.04 | 401.67 | 21 |
| 2 / 关闭 | 9.64 | 0.718 / 0.096 / 14.227 | 739.22 | 2.16 | 1857 |
| 2 / 开启 | 8.35 | 0.111 / 0.028 / 10.302 | 529.87 | 252.66 | 383 |

CPU 按全部 12 个逻辑处理器归一；工作耗时为末五窗口各自每次工作的均值再平均。场景图只测 updatePaintNode CPU 工作。四组最终文字布局缓存均为 3276 项；既有图片准备预算造成文本节点回退，计数与原因保存在报告中，该行为不是自适应新增的画质降级。内存和纹理估算仅为结束时快照。限帧主动等待单独记录，不算入上述工作耗时。

## 证据与未验证范围

- DPR 1：`out/validation/frame-rates-20261014-060352-255/`，包含环境、XML、每轮设置、完整逐秒报告和 summary.json。
- DPR 2：`out/validation/frame-rates-20261014-060745-501/`，结构同上。
- 没有真实视频背景对照、长时间温度 / 功耗测量、GPU 专用计时或光学测量。本次不能推广到其他硬件。
- 144/165 Hz 物理显示器的 60 Hz 节奏、实际 120 Hz、自适应跨屏及混合 DPI 尚待实机验收。核心测试覆盖模拟 60/144/165/240 Hz 时刻的绝对截止调度，不能替代这些实测。
