# 播放中心

侧栏 **播放** 页面与底部全宽播放条共同构成 DanmaX 的播放中心。切换浏览页面不会中断当前播放任务；视频同步与独立弹幕两种互斥任务共用唯一引擎、帧驱动与覆盖层。

## 1. 界面布局与呈现

- **底部播放条**：左侧仅显示文字信息（不含缩略图），上行为进度条，下行为居中的“后退 10 秒 / 播放或暂停 / 前进 30 秒”主控按钮组，右侧为弹幕、播放器、全屏与更多菜单。
- **内置观看模式**：使用开发版内置播放器位于播放页时隐藏侧栏，窗口模式下固定显示底栏，全屏模式下空闲 3 秒自动隐藏（暂停、菜单打开、定位等待或拖动时常显）。`F11` 或底栏按钮切换全屏，`Escape` 优先关闭弹窗再退出全屏，返回按钮回到最近浏览页并继续后台播放。详细规则见 [播放底栏与内置观看布局](../playback/playback-presentation.md)。

## 2. 核心操作入口

| 入口 | 行为语义 |
|---|---|
| **打开视频** / 全局拖入视频 | 验证文件与默认播放器，建立受控实例，确认媒体并恢复历史进度，再自动准备弹幕 |
| **更多 → 独立播放弹幕 XML** | 不启动播放器，异步解析 XML 成功后交接并从零启动独立弹幕时钟；失败或取消保留原任务 |
| **弹幕** 菜单 | 控制显示/隐藏、加载/更换 XML、在线搜索、缓存选择与卸载（均作用于当前任务）；视频任务额外提供“重新匹配”，独立任务不识别文件名 |
| **播放器** 菜单 | 仅在视频同步任务中提供预设相关操作 |
| **更多 → 结束播放** / 悬浮条停止 | 结束当前任务。拥有受控 PotPlayer/VLC 时请求正常关闭；独立任务仅关闭弹幕层 |

> [!IMPORTANT]
> 当前无活动任务时，禁止通过在线搜索或缓存列表隐式启动独立播放；用户必须先明确打开视频或选择独立 XML 入口。

## 3. 控制语义与能力边界

- **视频同步任务**：播放/暂停与定位命令均需校验实例身份、内容 ID、任务代次及采样新鲜度，并等待后端执行与位置读回。
- **独立弹幕任务**：由本地单调时钟驱动，底栏与快捷工具栏直接控制暂停、继续与进度拖动，无媒体采样依赖。
- **拖动与定位**：鼠标拖动仅更新界面预览，松手提交缓存草稿目标，等待期间保持目标显示；连续操作仅保留最后一条尚未发送的目标。详见 [公共定位事务](seek-transactions.md)。
- **已知协议边界**：PotPlayer 原生消息协议当前无已验证的完整路径或倍速查询接口，窗口标题与时长不作为换片依据，播放器内部手动换片或自动连播下一集无法保证自动识别（建议通过 DanmaX 打开下一集）。实际验证范围见 [当前交付状态](../status/current-status.md)。

## 4. 数据隔离与投影

- 视频元信息与弹幕来源分别维护：更换弹幕来源不改写视频名称或封面；独立任务仅展示自身 XML 文件名或在线番剧信息，不写入 `recent-videos.json`。
- 应用启动时不自动恢复播放，仅保留历史配置、缓存与最近播放记录。
