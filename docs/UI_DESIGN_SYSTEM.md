# Qt 官方 FluentWinUI3 界面规范

## 当前播放布局

按用户要求，侧栏第二项统一为“播放”：中间展示封面／Fluent 占位图标、标题、分集、来源和状态，整窗底部常驻 Qt 官方控件组成的全宽播放条，横跨侧栏与内容区。播放条位于页面滚动容器外，不被页面滚动条或留白滚轮覆盖；暂停控制真实时间轴，弹幕显示开关单独管理。来源与跟随模式初版复用可展开设置。媒体库不再重复展示当前任务控制面板。已有卡片规范继续用于设置、来源和最近列表；播放信息区采用轻量布局。详见 NOW_PLAYING.md。

2026-10-08：用户授权返回 Qt 官方 FluentWinUI3，并以官方默认控件和简单布局替代第三方 FluentUI 与仿 Windows 设置卡片。本决定取代此前第三方库迁移方案。

## 控件与组合边界

- 页面编译期导入 `QtQuick.Controls.FluentWinUI3`，不显式导入 Basic/Fusion 或第三方 FluentUI。Qt 官方模块内部的 Fusion 回退保留，尤其 ScrollBar；不宣称原生 WinUI 或像素级一致。
- 按钮、开关、输入框、下拉主体、标准选项、滑块、标签页、对话框、滚动条保持官方默认背景、内容实现、字体、圆角和交互状态。不访问 Qt 私有样式 API。
- Qt 6.11 的纯文字 TabButton 通过 icon.color 取得标签颜色，而默认值透明；允许将公开 icon.color 绑定 palette.buttonText，保留默认内容与背景。
- 主窗上部采用侧栏与内容并排布局，下部由全宽播放条独占；侧栏、主内容背景和垂直分隔线止于播放条顶部。
- 导航侧边栏采用标准 ItemDelegate 并在所有窗口宽度下常驻显示（窄屏收缩为纯图标模式），通过 1 像素垂直分隔线与主内容区清晰隔离；选中的导航项呈现醒目的左侧主题色胶囊指示条（Pill Indicator）。上部为首页／播放／媒体库，底部为日志／关于／设置；复用同一导航项实现。图标基准 20，图文间距 12，展开左右内边距 16／12；图标与行高响应文字缩放，窄栏随图标所需尺寸扩展，保留键盘焦点、可访问名称与窄栏提示。
- 内容分组与设置面板统一以 WinUI 3 原生卡片体系为基准：SettingsRow 升级为独立设置条目卡片（SettingsCard），ActionCard、SettingsRow 统一对接 Ui.cardMinHeight（70px）与 Ui.cardPaddingX/Y（16px 内衬），拥有独立的圆角、半透明背景与微细描边，卡片间以 4px 微间距（Ui.cardGap）垂直排列；SettingsSection 作为轻量分组容器，提供外置分组标题与说明（card 为 false 时无外层大底板，仅在复合控制面板上显式设为 true 提供整体卡片底板）。
- 文字缓存、诊断和关于默认展示；仅手动应用 ID、运行详情等可选内容使用标准 checkable Button 控制显隐。Disclosure 不模拟 Expander 外观，收起内部焦点返回按钮，隐藏内容不接受操作。
 - SettingsRow/ActionCard 共同构成全站规范的 Fluent 卡片项；SettingsSection 统一负责分组标题、说明与卡片流编排；PageFrame 负责页面标题、自适应可用宽度与统一滚动机制。保留公共布局组件避免页面重复代码，不以文件数量衡量自定义程度。
 - **图标库统一约束**：严禁在 QML 中自绘 Canvas、手绘 SVG 或以基础几何图形拼接图标。应用功能图标统一采用微软官方 Fluent System Icons SVG，通过 `resources/fluent/manifest.json` 锁定来源提交、原稿与深色改色稿哈希，并由 `scripts/verify-fluent-assets.ps1` 离线校验；`scripts/prepare-fluent-assets.ps1 -Offline` 按原路径仅替换颜色重建深色稿，不手改几何。通过 `Ui.icon(name)` 调用；标准控件使用官方 icon 着色，装饰图使用 `FluentIcon` 按逻辑尺寸×DPR 请求 SVG 解码尺寸，跨屏重新请求尺寸。高对比度隐藏非必要装饰图，保留文字与标准控件语义着色，实际高对比度仍须单独验收。标题栏最小化／最大化／还原／关闭及外链标识也使用官方 SVG；标题栏使用可键盘访问的 ToolButton 并保留 QWindowKit 挂接，关闭状态颜色集中于 Ui。品牌 Logo、封面及 Qt 官方控件内部图形不属于本条 SVG 迁移范围。QtSvg 动态部署须包含 qsvg／qsvgicon，静态 Qt 锁须包含 qtsvg 与对应插件。

## 主题、材质和布局

- 系统/浅色/深色由 Qt styleHints 与官方 palette 管理；不维护第二套控件颜色或覆盖控件字体。Ui 只集中应用标题字阶、页面间距、图标路径和 Mica 窗口背景等语义。
- Mica 和沉浸式标题栏通过 QWindowKit 与 WindowBackdropController 协同管理，仅作用于主窗。主窗口布局遵循 WinUI 3 经典的分层材质对比：整窗作为单层 Mica 底板，左侧导航栏保持完全透明直接透出原生 Mica，右侧主内容区叠加半透明基底色（Ui.contentAreaSurface），两者均自顶部（y=0）延伸至全宽播放条上沿，中间以 1px 细微描边分割，形成左轻右实、两边皆具 Mica 质感的分层视觉。通过 QWindowKit 原生挂接 Windows 11 Snap Layouts 贴靠菜单与窗口移动/最大化动画。全站卡片容器采用统一的 Ui.cardBackground（深色模式透光率 5%，浅色模式 70%）与 1px Ui.cardBorder，既保持与底层 Mica 或纯色底板的良好分层呼吸感，又确保高对比度模式下无障碍可读性。
- 页面最大宽度 1040、组间距 24、宽窗边距 32、窄窗 16。设置编辑器按宽度移至说明下方；长文本可换行。标准控件自身尺寸由官方风格决定。
- 所有设置继续即时生效与保存，编辑完成校验提交，保留错误、重试与恢复默认。弹幕覆盖层、时间轴和轨道逻辑不参与界面迁移。

## 下拉与滚动

- 2026-10-17 浮层视觉微调：文字统一距选项左侧 12，3×16 指示条独立置于左侧 2；选项垂直内衬 8、行高至少 36 并响应字体。选中／悬停底板在浮层背景内绘制，左右各留 4，覆盖滚动通道底色，但文字视口和标准滚动条仍隔离，不改变滚动条显隐时的内容布局。背景采用集中于 Ui 的冷调浅白／炭灰与低对比描边，维持不透明回退语义。
- `PopupSurface` 复用 Qt 自带公开 `RectangularShadow`，仅在浮层可见且图形后端支持时创建；模糊范围 12、向下偏移 3、浅深阴影透明度分别 16%／32%。浮层距主窗边缘预留 20 以容纳阴影，阴影不扩大选项命中区域；软件后端／高对比度禁用阴影。保留外层 8、内层 4 圆角，不宣称 Windows 原生 ThemeShadow 或 Acrylic，不新增依赖。
- 2026-10-17 下拉交互优化：非编辑且有有效选择时，展开浮层覆盖原字段，当前行中心与字段中心对齐；只隐藏原文字、箭头和背景的可见外观，保留控件布局、焦点与无障碍语义，关闭后立即恢复。短列表显示可用候选，长列表按当前项及上下空间分配可见行，剩余候选通过标准滚动条访问。可编辑字段、未选中项和空列表沿用上下展开，不遮住编辑区。所有分支继续限制窗口边距与高度；不为外观引入原生宿主、Qt 私有调用或新依赖。
- 2026-10-17 按用户要求，菜单与下拉浮层统一使用 `PopupSurface`：公开 QML 圆角／描边和语义纯色背景，不再使用预烘焙背景图片，避免纹理噪点与缩放痕迹；标准菜单项和控件主体交互保持 Qt 官方实现。该表面是纯色回退，不宣称 Acrylic 或 Mica。真实浮层材质尚未接入。
- `AppComboBox` 与 `AppMenu` 使用应用自身公开的展开进度，250ms OutCubic 从 33% 展开至完整高度；不依赖 Qt 样式私有变量。有选择的非编辑下拉围绕选中行展开，展开过程中同步列表偏移，避免候选从错误位置跳入；其余分支固定靠近字段的边缘。系统关闭动画或高对比度时直接打开，不增加关闭等待。
- AppComboBox 当前在 ComboBox 基础上自定义弹出浮层背景（8px 圆角、微细描边、深浅色浮层）及 4px 内嵌胶囊条 delegate，并附加标准 ScrollBar，限制尺寸、窗口内定位与当前项可见性。Qt 6.11.0 源码已有官方 Fluent ComboBox 弹层，原“ComboBox 弹层回退 Fusion”的笼统归因不成立；当前实现和 Qt 官方风格都不能称为原生 WinUI 控件。真正 WinUI 3 的独立验证及尚未解决的接入边界见 [XAML Islands 评估](WINUI_XAML_ISLANDS_EVALUATION.md)，不表示生产组件已迁移。
- 长列表最高 360×文本缩放，受窗口可用空间约束，距窗口边缘至少 8。保留 F4/Alt+Down、末尾当前项、缩窗和上下展开的回归检查。
- 下拉选项继承所属 ComboBox 的字体、字号与字重；字体选择器仅按选项名称覆盖字体族。不得用空字体名表示继承，避免匹配至旧式字体；行高至少容纳文字及官方上下内边距。
- 所有控制界面（整页、内嵌列表、弹窗、下拉浮层及横向番剧列表）复用 `AppScrollBar` 的布局与滚轮适配。通过公开 API 调整父容器、位置、长度并处理悬停区域的滚轮，保留 Qt 官方背景、内容实现、完整交互宽度、悬停、拖动和淡出行为，启用方向的策略统一为 `AsNeeded`，不需要的方向使用 `AlwaysOff`。不得重画滚动条或强制常驻粗滑块。无溢出时判断滑块状态，不要求 ScrollBar 对象本身隐藏。
- 滚动条放在内容视口之外、所属容器之内的独立留白通道，完整交互区域距容器边缘 `Ui.scrollEdgeInset`（4 逻辑单位），与内容至少间隔 `Ui.scrollGap`（8）。`Ui.scrollInset()` 根据官方 `implicitWidth`／`implicitHeight` 与布局最小内边距取较大值，并按 4 单位向上取整；按完整交互区域计算，不能按可见细滑块计算。滚动条只覆盖对应视口长度，避免侵入标题、筛选器及底部动作区。
- 滚动条显隐、激活及溢出状态变化不改变内容宽高；容器统一预留空间后，条目不得再次扣减滚动条宽度。整页与有底板的内容区保持左右对称内边距，页面以宽窗 32／窄窗 16 为下限，必要时为完整交互区域扩大两侧留白；主窗口和 PageFrame 不重复预留边距。横向列表在卡片下方预留独立通道，规则沿对应轴向应用。下拉浮层保留既有 4 单位选项内嵌，仅由右侧通道负责滚动条留白。
- 滚动条应位于视口裁切范围外且仍在所属容器边界内，保留附加 ScrollBar 与原有 Flickable／ListView 的联动；不能因重设父项而丢失拖动、悬停或访问名称。嵌套列表保留现有滚轮分工，横向列表上的纵向输入继续交给页面。
- 外置滚动条通过 AppScrollBar 统一处理悬停区域的滚轮，明确关联真实 Flickable（ScrollView 需提供其 contentItem），不能仅设置 wheelEnabled。像素增量优先于角度增量，角度步长复用 Ui；按 origin、视口尺寸及内容边距限制范围，纵向列表在边界或无溢出时不误滚外层页面。横向番剧列表的普通纵向输入显式交给页面，横向输入及 Shift＋滚轮控制列表。处理区不接受鼠标按钮，保留官方拖动；验收须覆盖滑块／轨道上的滚轮、像素／角度混合、双向边界、无溢出与嵌套目标。
- 滚轮覆盖以完整容器为准：AppScrollBar 的 wheelRegion 显式指向所属页面／列表／浮层容器，补齐左侧留白、视口到滚动条之间、外侧边缘及存在的上下留白。兜底只接收视口外未被子级消费的事件，接受 Mouse 与 TouchPad，横纵处理按实际像素／角度主轴去重；不以扩大可见滑块或铺盖交互控件的透明鼠标层实现。日志覆盖整页，服务弹窗仅覆盖列表高度范围，详情排除底部动作区。外部父项上的处理器随滚动条销毁释放，隐藏组件不得继续响应。验收必须逐点检查上述区域，不能用内容区和滑块两个位置代替。
- Qt 官方纹理、Fusion 回退等可见差异记录为边界，不以新增自绘补丁消除。
- 用户已决定暂缓真实 Acrylic 接入研究，优先落地下拉交互。独立材质探针及结果保留在 `ACRYLIC_POPUP_PROBE.md`；其中背景响应阈值仅评估该探针的 DWM 透底路径，不作为 WinUI 外观一致性的通用判据。正式组件接受纯色回退，不添加假材质标识。

## 首页番剧搜索

- 播放页的“跟随播放器”区域提供默认关闭的自动匹配标准 Switch，状态、识别结果、进度／取消、继续／重新匹配及忘记关联均留在主页面；独立播放不显示该工作流。失败／歧义进入统一的匹配弹窗，自动成功直接按媒体状态运行。主动搜索仅载入就绪，不请求暂停外部播放器；与自动匹配使用独立请求状态。手动停止／选源后显示已暂停，不自动抢回控制。

- 首页不保留常驻在线弹幕搜索或旧自动确认展开区。详情选集／卡片搜索直接打开统一 Fluent 弹窗，复用 OnlineDanmakuPane、AppComboBox 与 AppScrollBar 的独立留白通道；进度、取消、错误及重新下载留在弹窗。主动搜索隐藏恢复流程专用的文件名与暂停说明，载入成功关闭并进入播放页。播放页来源仅保留本地 XML／已缓存。
- 播放器选择保留已保存应用 ID；会话暂不可用时在下拉列表显示该等待项，避免选择变空。连接徽章依据新鲜且有效的媒体快照，区别“未绑定／等待已保存播放器／已连接”；不因列表出现 ID 就宣称连接。允许在会话缺席时开始等待，并提供取消绑定。状态文字可换行，徽章省略长 ID，颜色使用 Ui 语义层。

- 番剧封面统一使用后台缓存服务提供的本地图片源；图片不可用时沿用现有占位。过期元信息刷新期间保留内容并显示简短状态，失败保留本地内容及标准刷新按钮。详情和搜索结果的刷新操作跳过缓存有效期；图片首次可见时请求，已访问图片随组件保留来源与请求，页面隐藏不清空封面，组件销毁或主动清空缓存时释放。请求继续受既有数量和并发上限约束。
- 设置中的“番剧元信息缓存”分组使用现有 SettingsSection、SettingsRow 与 ActionCard，分别显示 JSON／封面占用及固定上限；清理动作显示进行中、成功或失败状态，不新增容量或有效期调节控件。

- 主窗口常规最小尺寸为 800×600 逻辑单位，默认启动尺寸保持 1080×760。当前屏幕可用工作区不足时，分别将宽高下限降低至工作区尺寸减 32 的边框余量；读取实际 QScreen 的 availableGeometry，不能用多个显示器的合并桌面尺寸替代。导航展开阈值仍为 1008。
- 首页搜索框与窗口按钮共用顶部横排，位于独立窗口按钮区域左侧的可用区域内居中，最大宽度 440 逻辑单位；右侧预留 48 单位拖拽空白，窄窗随剩余空间收缩。按用户要求采用紧凑高度：搜索框至少 28，且不低于文字内容加控件上下内边距。所有页面共用至少 44 的顶部高度，容纳搜索框及上下各 8 单位留白，即使搜索框隐藏也保留同一高度；内容区再留 8 单位标题间距，所有页面标题起点对齐。间距通过 Ui 语义层管理。输入区域通过 QWindowKit 公开 API 排除拖拽命中；其余空白保留标题栏行为。搜索框固定显示，不随页面滚动，不再单独占用内容行。搜索状态隐藏首页标题和说明，清空后恢复标题和推荐内容。
- 使用锁定 Qt 的官方 FluentWinUI3 `SearchField`，保留默认背景、指示按钮、字体、内边距和状态；紧凑高度为用户要求的局部例外。512 字符输入限制通过公开 `contentItem` 的 TextField 属性设置；回车与放大镜按钮分别接入控件公开的搜索事件。锁定版本内部模板不绘制占位文字，因此以仅显示文本的 Label 补充“搜索番剧”提示，沿用编辑器字体、内边距和语义提示色，输入或输入法预编辑时隐藏，不替换编辑器。
- 首版手动提交搜索，不逐键请求；结果在输入框下方通过标准 ItemDelegate 展示封面、中文名／原名、日期及可用评分，复用页面纵向滚动与现有详情弹层。最多展示相关度最高的 20 项，更多匹配提示细化关键词。
- 首页 Ctrl+F 聚焦输入，向下键进入首项，结果支持键盘激活；Escape 或清空按钮恢复推荐内容。切页清空搜索并取消请求。搜索加载、无结果、错误和重试均明确显示；远程标题以纯文本呈现。

## 异步内容加载

- 番剧详情先显示轻量弹窗，`opened` 后再请求数据并启用加载占位；打开途中关闭或切页不得触发延后的请求。剧集控件通过单个 `FrameAnimation` 增量追加，每帧最多 8 项，并在本批耗时达到 2ms 后让出（不是硬实时保证）。首批即可交互，预留当前页完整网格高度，避免后续追加改变页面高度；状态更新不重建相同剧集页，换页及关闭取消旧批次。不为每个按钮设置定时器或动画，减少动画模式仍保留分帧准备。
- 等待状态继续使用 Qt 官方 FluentWinUI3 BusyIndicator／ProgressBar，下载与 XML 读取保留真实进度和取消操作。Qt FluentWinUI3 不提供 Skeleton／Shimmer；内容占位通过统一 LoadingPlaceholder 组合公开 QML 矩形与布局能力实现，不引入 Windows XAML 或第三方库。
- 首页首次周历、番剧搜索、详情、分集、在线搜索与在线选集、首次缓存扫描使用对应内容形状的骨架。先预留布局，持续等待 150ms 才显示；已有内容的后台刷新保留原内容，快速缓存命中不闪骨架。静态设置、日志和关于不添加等待占位。
- 详情与分集独立报告加载状态，分集尚未返回时显示“加载中”，合法空列表返回后才显示无剧集。慢请求完成后内容整体淡入 180ms，不为每个剧集按钮创建动画；取消、错误、隐藏页面停止对应占位。
- 占位共享一次透明度脉冲，数量固定且有界；隐藏时停止。颜色、延迟、时长集中于 Ui。通过 SystemUiPreferences 读取 Windows 客户区动画设置并响应系统通知和重新激活；关闭动画或高对比度时占位静态显示，新增淡入和详情对话框过渡禁用。此规则不代表所有既有动画已统一改造。
- 骨架不接收焦点，使用一个可访问加载名称；真实内容沿用原有键盘与可访问语义。系统高对比度与 Narrator 的实际效果需单独验收。
- 封面由 CachedCoverImage 统一显示占位：等待缓存／下载时延迟显示骨架，所有可见封面共用一条透明度脉冲；无地址、失败或超时后转为静态骨架。图片到达后短暂淡入，缓存快速命中与页面重入不重播。卡片与详情不再使用标题首字或星号代替海报，标题、评分及键盘交互保留；单个封面骨架只作装饰，不重复朗读加载状态。

## 视频拖放反馈

- 外部播放器设置页只保留独立 SettingsRow 摘要和“管理播放器”入口。弹窗列出固定预设，每项展示名称、默认单选、预设同步方式、可编辑路径、验证状态、自动发现及选择程序；多个发现结果用 AppComboBox 供选择。不提供自定义增删、名称、参数、SMTC 和同步开关，也不暴露 VLC 端口／密码。路径与默认项采用草稿，输入完成后校验，保存时重新验证并原子提交，取消／Escape／离开设置页丢弃；底部动作固定，内容滚动复用 AppScrollBar 留白通道，显式关联完整所属容器并限制视口高度。路径通过不表示同步验收，运行时仍核实真实媒体。

- 首页不显示打开视频动作卡片；播放页保留文件选择入口。主窗口以统一 DropArea 覆盖侧栏、标题栏与页面留白，有效的单个本地视频进入后显示居中提示、纯文本文件名及主题色边框；弹窗打开时停用，不干扰弹窗输入。
- 使用 Qt 官方 QtQuick.Effects.MultiEffect 模糊主界面，背景源与提示、拖放检测器分离。进入时捕获一次背景，尺寸或 DPI 变化才更新；纹理最长边不超过 1600 像素。离开、松手、Escape、隐藏或禁用后通过 Loader 销毁纹理及特效，不增加常态合成。软件渲染与高对比度使用语义主题纯色反馈，提示保持清晰；反馈动画遵从减少动画设置。
- 此效果仅用于主面板，不作用于独立弹幕窗口或播放器；不采样桌面 Mica 材质。
- 拖放背景采用较厚的主题底色遮罩（深色 75%、浅色 80% 不透明度）、40 模糊上限及 -0.65 饱和度调整，让页面内容退到次要位置；中央提示保持清晰，不另加卡片底板。

## 覆盖层调试信息

- 默认宽度 320 逻辑单位，受所选屏幕宽度和两侧 16 单位边距约束；不由媒体标题或指标的自然宽度决定。保留四角定位和现有覆盖层穿透、焦点策略。
- 状态、媒体标题与指标独立排布，均按纯文本显示。状态单行省略；标题最多两行，支持连续英文换行，尾部省略，空标题不占行。仅在显示时整理标题换行与制表符，后端和报告保留完整标题。
- 指标完整展示，窄屏允许换行，高度按内容计算；不添加悬停浮层、滚动字幕、用户配置或计时器。内部字号变化时宽度按比例调整，但仍受屏幕宽度约束。

## 弹幕快捷工具栏

- 弹幕窗口独立于主面板，工具栏以弹幕窗口为所属窗口；正在运行且主面板或其所属对话框位于 Windows 前台时，原生层级保持“所属对话框 → 工具栏及其浮层／提示 → 主面板 → 弹幕”，面板外弹幕继续显示。工具栏保留固定／顶部感应／离开自动隐藏规则，进入面板不关闭浮层、不撤销拖动；模态输入遵守 Qt 规则。面板最小化、切回播放器或停止后恢复原生置顶状态及播放器前台限制，不暂停媒体时钟。
- “仅播放器前台显示”包含主面板操作例外；不新增用户配置。面板提升失败时暂时隐藏弹幕并重试。临时层级使用不激活窗口的原生定位，不改变 Qt 窗口标志及材质。
- 快捷工具栏提示使用官方 ToolTip 的 `Popup.Window`，放在按钮下方并留出原生阴影内衬，避免短窗口内的提示覆盖按钮；显示许可撤销时同时关闭提示，不抢占焦点。
- 未固定时离开工具栏与浮层整体区域 1 秒后完全隐藏，不保留可见把手或透明拦截窗口。顶部感应带与主工具栏底板同宽、高 10 逻辑单位，并沿所选屏幕居中对齐；宽度绑定实际布局，随播放模式、文字缩放及窄屏换行更新，不包括浮层和宿主透明内边距。隐藏后保持宽度计算，仅在覆盖层允许显示时以 GUI 线程 50ms 坐标采样感应。
- 不透明度浮层与工具栏之间的间隙包含在感应区域内。按钮按下及滑块拖动期间保持显示，释放后重新评估离开计时；固定时离开只关闭浮层。
- 展开内容与原生窗口生命周期分离，保持完整尺寸直至收起动画结束。覆盖层隐藏或播放停止时关闭浮层并清除临时展开状态，保留本次运行的固定状态。普通工具栏操作不激活窗口。
- 工具栏提示保持官方 Fluent 背景、字体及内边距，使用纯文本单行内容，按自然文字宽度展开，禁止随按钮宽度换行。暂停、停止、进度、清屏提示分别为“暂停”“停止并退出”“播放进度”“一键清屏”；跟随模式的停止仍只退出覆盖层。
- 独立模式提供暂停／继续、停止、前后 5 秒跳转与进度浮层；跟随模式只提供退出覆盖层与同步偏移，不控制播放器。停止保留弹幕，主面板另外提供卸载；两者文案不可混用。
- 进度浮层与不透明度浮层互斥，拖动预览、释放提交一次，并保持原播放状态。进入面板或显示许可撤销时取消尚未提交的拖动；两种浮层共用悬停及固定策略。
- 工具栏按所选屏幕宽度限制尺寸，窄屏以完整功能组换行，高度随内容变化；原生窗口和指针检测使用实际完整尺寸，收起动画期间也不提前缩小。

## 验收与依赖

- 自动匹配失败使用官方 Fluent `Dialog`，含原始媒体标题只读可选择输入区、复制动作、原因／暂停状态、复用在线搜索与级联选集，以及独立底部取消动作。Escape 与取消等价，禁用点击外侧关闭，切换内容自动关闭。正文采用 AppScrollBar 独立留白通道，滚轮范围显式截止于 footer，长候选复用 AppComboBox；仅当本次暂停已确认时恢复播放器。

- 首页内容设置提供默认关闭的“首页显示国漫”，即时保存，仅影响首页推荐、周历与高分榜；搜索、最近在看及本地缓存不受影响。仅隐藏已确认的国漫，地区未知或冲突时保留；初次分类等待复用骨架，不先展示待判定卡片。
- 番剧详情标签合并完整的公共标签与普通标签，去重后公共标签优先。在剧集区下方独立展示，收起时按可用宽度显示最多一行并为末尾“展开”按钮预留空间，全部可容纳时隐藏按钮；展开时显示全部标签并将“收起”按钮放在标签流末尾。按钮保留官方背景与交互状态，作为紧凑操作允许采用标签字号、高度与内边距。收起时超长标签单行省略，展开时在可用宽度内换行，不挤占顶部海报与剧集按钮。
- 首页横向列表上的纵向滚轮和触控板纵向手势滚动页面；横向手势、Shift＋滚轮、拖动与左右按钮滚动列表。列表启用复用及一屏预留范围，近期已验证封面采用有界保留，回看优先复用缓存。
- 详情只在媒体卡片展示番剧标题，去掉重复的可见弹窗标题、顶部加载条和常驻刷新按钮；保留弹窗名称与错误区域重试。首次加载或剧集切组使用骨架，已有内容后台刷新保持原内容。
- 详情内容视口四边采用统一内边距，下边相对底部动作区；原生纵向滚动条独立放在右侧留白内，距弹窗边缘 4 单位，不额外扣减内容宽度。统一内边距至少容纳滚动条完整交互宽度、8 单位内容间隔及边缘间隔，按 4 单位节奏向上取整；滚动条仅覆盖视口高度，显隐不改变内容布局。
- 剧集每组最多 100 项，分页控制器（紧凑方块前后翻页按钮与固定紧凑宽度的 AppComboBox 范围选择）内嵌置于剧集标题行右侧，多页时展示，单页时自动隐藏，消除横向过度拉伸与纵向视口浪费；按需读取并缓存当前组，显示接口总数。只创建当前组的剧集按钮，保留未播出禁用、悬停提示、键盘操作与关闭取消。

- 正式构建/部署不依赖第三方 FluentUI、其单例或 GraphicalEffects。现有静态 Qt SDK 的额外模块无需删除，但不能作为应用依赖宣传。库调研工具仅供历史复现，不作为正式构建前置步骤。
- Qt Test/CTest 验证配置、Mica 策略、导航、按钮折叠焦点、原播放/服务编辑/日志、长下拉滚动与键盘。软件纯色截图只用于布局。
- 三页浅深主题、520/800/1080 宽度、放大文字与 DPI、页面实际滚到底和弹出长列表应验证；Mica 使用桌面合成截图。Narrator、高对比度、跨屏、净机和性能需独立记录，未验收不得宣称完成。
