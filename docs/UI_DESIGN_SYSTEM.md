# Qt 官方 FluentWinUI3 界面规范

2026-10-08：用户授权返回 Qt 官方 FluentWinUI3，并以官方默认控件和简单布局替代第三方 FluentUI 与仿 Windows 设置卡片。本决定取代此前第三方库迁移方案。

## 控件与组合边界

- 页面编译期导入 `QtQuick.Controls.FluentWinUI3`，不显式导入 Basic/Fusion 或第三方 FluentUI。Qt 官方模块内部的 Fusion 回退保留，尤其 ScrollBar；不宣称原生 WinUI 或像素级一致。
- 按钮、开关、输入框、下拉主体、标准选项、滑块、标签页、对话框、滚动条保持官方默认背景、内容实现、字体、圆角和交互状态。不访问 Qt 私有样式 API。
- Qt 6.11 的纯文字 TabButton 通过 icon.color 取得标签颜色，而默认值透明；允许将公开 icon.color 绑定 palette.buttonText，保留默认内容与背景。
- 导航侧边栏采用标准 ItemDelegate 并在所有窗口宽度下常驻显示（窄屏收缩为纯图标模式），通过 1 像素垂直分隔线与主内容区清晰隔离；选中的导航项呈现醒目的左侧主题色胶囊指示条（Pill Indicator）。
- 内容分组与设置面板统一以 WinUI 3 原生卡片体系为基准：SettingsRow 升级为独立设置条目卡片（SettingsCard），ActionCard、SettingsRow 统一对接 Ui.cardMinHeight（70px）与 Ui.cardPaddingX/Y（16px 内衬），拥有独立的圆角、半透明背景与微细描边，卡片间以 4px 微间距（Ui.cardGap）垂直排列；SettingsSection 作为轻量分组容器，提供外置分组标题与说明（card 为 false 时无外层大底板，仅在复合控制面板上显式设为 true 提供整体卡片底板）。
- 文字缓存、诊断和关于默认展示；仅手动应用 ID、运行详情等可选内容使用标准 checkable Button 控制显隐。Disclosure 不模拟 Expander 外观，收起内部焦点返回按钮，隐藏内容不接受操作。
 - SettingsRow/ActionCard 共同构成全站规范的 Fluent 卡片项；SettingsSection 统一负责分组标题、说明与卡片流编排；PageFrame 负责页面标题、自适应可用宽度与统一滚动机制。保留公共布局组件避免页面重复代码，不以文件数量衡量自定义程度。
 - **图标库统一约束**：严禁在 QML 中自绘 Canvas、手绘 SVG 或以基础几何图形拼接图标。所有图标必须统一来自于微软官方 Fluent System Icons 库（通过 `resources/fluent/` 清单集中管理、离线预渲染 60×60 PNG 且通过 `scripts/verify-fluent-assets.ps1` 校验哈希），通过 `Ui.icon(name)` 规范调用，确保在深浅模式与各种 DPI 缩放下的绝对清晰与设计一致性。

## 主题、材质和布局

- 系统/浅色/深色由 Qt styleHints 与官方 palette 管理；不维护第二套控件颜色或覆盖控件字体。Ui 只集中应用标题字阶、页面间距、图标路径和 Mica 窗口背景等语义。
- Mica 和沉浸式标题栏通过 QWindowKit 与 WindowBackdropController 协同管理，仅作用于主窗。主窗口布局遵循 WinUI 3 经典的分层材质对比：整窗作为单层 Mica 底板，左侧导航栏保持完全透明直接透出原生 Mica 并自顶部（y=0）一通到底，右侧主内容区叠加半透明基底色（Ui.contentAreaSurface）自顶部（y=0）一通到底，中间以 1px 细微描边分割，形成左轻右实、两边皆具 Mica 质感的分层视觉。通过 QWindowKit 原生挂接 Windows 11 Snap Layouts 贴靠菜单与窗口移动/最大化动画。全站卡片容器采用统一的 Ui.cardBackground（深色模式透光率 5%，浅色模式 70%）与 1px Ui.cardBorder，既保持与底层 Mica 或纯色底板的良好分层呼吸感，又确保高对比度模式下无障碍可读性。
- 页面最大宽度 1040、组间距 24、宽窗边距 32、窄窗 16。设置编辑器按宽度移至说明下方；长文本可换行。标准控件自身尺寸由官方风格决定。
- 所有设置继续即时生效与保存，编辑完成校验提交，保留错误、重试与恢复默认。弹幕覆盖层、时间轴和轨道逻辑不参与界面迁移。

## 下拉与滚动

- AppComboBox 在 ComboBox 基础上规范了 WinUI 3 风格的弹出浮层（8px 圆角、微细描边、深浅色浮层材质、4px 内嵌胶囊条 delegate），并附加标准 ScrollBar，限制尺寸、窗口内定位与当前项可见性，彻底解决 Qt 官方对 ComboBox 弹窗回退至旧式 Fusion 黑框的问题。
- 长列表最高 360×文本缩放，受窗口可用空间约束，距窗口边缘至少 8。保留 F4/Alt+Down、末尾当前项、缩窗和上下展开的回归检查。
- 页面和列表预留滚动条空间；保持官方默认 active/hover/policy，不强制常驻粗滑块。无溢出时判断滑块状态，不要求 ScrollBar 对象本身隐藏。
- Qt 官方纹理、Fusion 回退等可见差异记录为边界，不以新增自绘补丁消除。

## 首页番剧搜索

- 番剧封面统一使用后台缓存服务提供的本地图片源；图片不可用时沿用现有占位。过期元信息刷新期间保留内容并显示简短状态，失败保留本地内容及标准刷新按钮。详情和搜索结果的刷新操作跳过缓存有效期；图片首次可见时请求，已访问图片随组件保留来源与请求，页面隐藏不清空封面，组件销毁或主动清空缓存时释放。请求继续受既有数量和并发上限约束。
- 设置中的“番剧元信息缓存”分组使用现有 SettingsSection、SettingsRow 与 ActionCard，分别显示 JSON／封面占用及固定上限；清理动作显示进行中、成功或失败状态，不新增容量或有效期调节控件。

- 主窗口常规最小尺寸为 800×600 逻辑单位，默认启动尺寸保持 1080×760。当前屏幕可用工作区不足时，分别将宽高下限降低至工作区尺寸减 32 的边框余量；读取实际 QScreen 的 availableGeometry，不能用多个显示器的合并桌面尺寸替代。导航展开阈值仍为 1008。
- 首页搜索框与窗口按钮共用顶部横排，位于独立窗口按钮区域左侧的可用区域内居中，最大宽度 440 逻辑单位；右侧预留 48 单位拖拽空白，窄窗随剩余空间收缩。按用户要求采用紧凑高度：搜索框至少 28，且不低于文字内容加控件上下内边距。所有页面共用至少 44 的顶部高度，容纳搜索框及上下各 8 单位留白，即使搜索框隐藏也保留同一高度；内容区再留 8 单位标题间距，所有页面标题起点对齐。间距通过 Ui 语义层管理。输入区域通过 QWindowKit 公开 API 排除拖拽命中；其余空白保留标题栏行为。搜索框固定显示，不随页面滚动，不再单独占用内容行。搜索状态隐藏首页标题和说明，清空后恢复标题和推荐内容。
- 使用锁定 Qt 的官方 FluentWinUI3 `SearchField`，保留默认背景、指示按钮、字体、内边距和状态；紧凑高度为用户要求的局部例外。512 字符输入限制通过公开 `contentItem` 的 TextField 属性设置；回车与放大镜按钮分别接入控件公开的搜索事件。锁定版本内部模板不绘制占位文字，因此以仅显示文本的 Label 补充“搜索番剧”提示，沿用编辑器字体、内边距和语义提示色，输入或输入法预编辑时隐藏，不替换编辑器。
- 首版手动提交搜索，不逐键请求；结果在输入框下方通过标准 ItemDelegate 展示封面、中文名／原名、日期及可用评分，复用页面纵向滚动与现有详情弹层。最多展示相关度最高的 20 项，更多匹配提示细化关键词。
- 首页 Ctrl+F 聚焦输入，向下键进入首项，结果支持键盘激活；Escape 或清空按钮恢复推荐内容。切页清空搜索并取消请求。搜索加载、无结果、错误和重试均明确显示；远程标题以纯文本呈现。

## 覆盖层调试信息

- 默认宽度 320 逻辑单位，受所选屏幕宽度和两侧 16 单位边距约束；不由媒体标题或指标的自然宽度决定。保留四角定位和现有覆盖层穿透、焦点策略。
- 状态、媒体标题与指标独立排布，均按纯文本显示。状态单行省略；标题最多两行，支持连续英文换行，尾部省略，空标题不占行。仅在显示时整理标题换行与制表符，后端和报告保留完整标题。
- 指标完整展示，窄屏允许换行，高度按内容计算；不添加悬停浮层、滚动字幕、用户配置或计时器。内部字号变化时宽度按比例调整，但仍受屏幕宽度约束。

## 弹幕快捷工具栏

- 弹幕窗口独立于主面板，工具栏以弹幕窗口为所属窗口；正在运行且主面板或其所属对话框位于 Windows 前台时，原生层级保持“所属对话框 → 工具栏及其浮层／提示 → 主面板 → 弹幕”，面板外弹幕继续显示。工具栏保留固定／顶部感应／离开自动隐藏规则，进入面板不关闭浮层、不撤销拖动；模态输入遵守 Qt 规则。面板最小化、切回播放器或停止后恢复原生置顶状态及播放器前台限制，不暂停媒体时钟。
- “仅播放器前台显示”包含主面板操作例外；不新增用户配置。面板提升失败时暂时隐藏弹幕并重试。临时层级使用不激活窗口的原生定位，不改变 Qt 窗口标志及材质。
- 快捷工具栏提示使用官方 ToolTip 的 `Popup.Window`，放在按钮下方并留出原生阴影内衬，避免短窗口内的提示覆盖按钮；显示许可撤销时同时关闭提示，不抢占焦点。
- 未固定时离开工具栏与浮层整体区域 1 秒后完全隐藏，不保留可见把手或透明拦截窗口。顶部感应带与主工具栏底板同宽、高 10 逻辑单位，并沿所选屏幕居中对齐；宽度绑定实际布局，随播放模式、文字缩放及窄屏换行更新，不包括浮层和宿主透明内边距。隐藏后保持宽度计算，仅在覆盖层允许显示时以 GUI 线程 50ms 坐标采样感应。
- 不透明度浮层与工具栏之间的间隙包含在感应区域内。按钮按下及滑块拖动期间保持显示，释放后重新评估离开计时；固定时离开只关闭浮层。
- 展开内容与原生窗口生命周期分离，保持完整尺寸直至收起动画结束。覆盖层隐藏或播放停止时关闭浮层并清除临时展开状态，保留本次运行的固定状态。普通工具栏操作不激活窗口。
- 工具栏提示保持官方 Fluent 背景、字体及内边距，使用纯文本单行内容，按自然文字宽度展开，禁止随按钮宽度换行。暂停、停止、进度、清屏提示分别为“暂停”“停止并退出”“播放进度”“一键清屏”；跟随模式的停止仍只退出覆盖层。
- 独立模式提供暂停／继续、停止、前后 5 秒跳转与进度浮层；跟随模式只提供退出覆盖层与同步偏移，不控制播放器。停止保留弹幕，主面板另外提供卸载；两者文案不可混用。
- 进度浮层与不透明度浮层互斥，拖动预览、释放提交一次，并保持原播放状态。进入面板或显示许可撤销时取消尚未提交的拖动；两种浮层共用悬停及固定策略。
- 工具栏按所选屏幕宽度限制尺寸，窄屏以完整功能组换行，高度随内容变化；原生窗口和指针检测使用实际完整尺寸，收起动画期间也不提前缩小。

## 验收与依赖

- 正式构建/部署不依赖第三方 FluentUI、其单例或 GraphicalEffects。现有静态 Qt SDK 的额外模块无需删除，但不能作为应用依赖宣传。库调研工具仅供历史复现，不作为正式构建前置步骤。
- Qt Test/CTest 验证配置、Mica 策略、导航、按钮折叠焦点、原播放/服务编辑/日志、长下拉滚动与键盘。软件纯色截图只用于布局。
- 三页浅深主题、520/800/1080 宽度、放大文字与 DPI、页面实际滚到底和弹出长列表应验证；Mica 使用桌面合成截图。Narrator、高对比度、跨屏、净机和性能需独立记录，未验收不得宣称完成。
