## Windows 媒体播放器前台识别修复（2026-10-07）

实机捕获：媒体播放器前台 HWND 属于 ApplicationFrameHost；该进程的 GetApplicationUserModelId 返回 15703（无应用身份），但窗口属性 PKEY_AppUserModel_ID 等于所选 Microsoft.ZuneMusic AUMID。旧版只按进程识别，开启“仅播放器在前台显示”后会错误隐藏覆盖窗；置顶策略不能恢复被隐藏的窗口。

修复：优先读取前台窗口属性中的应用身份，保留桌面播放器的进程匹配。新增窗口身份匹配、不同应用拒绝、桌面进程回退与空窗口测试。只增加 Windows SDK 自带 shell32/ole32 链接，无第三方依赖。此修复不代表解决了独占全屏或其他置顶窗口竞争。
