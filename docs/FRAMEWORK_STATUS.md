# C++ 重构交付状态

版本：0.2；验证日期：2026-10-07。本页区分代码实现、自动化验证和仍需人工验收的系统行为。

## 已实现

- 纯 C++20 时间轴、滚动/顶部/底部调度、共用防重叠轨道、有界活动池；暂停冻结、跳转清空、隐藏后不补发历史弹幕。
- Qt 流式 XML 后台解析及可取消排序；错误定位、无效记录过滤、512 MiB/100 万条/512 字符边界；3600 条独立测试夹具。
- C++/WinRT SMTC 会话发现、按所选 ID 跟随位置/速率/暂停/媒体切换，超时暂停；独立播放、暂停、跳转。
- QQuickItem + 公开 QSGTextNode 渲染，活动文字布局和节点复用，单一 C++ 帧驱动；不使用 Qt 私有 API、逐弹幕 QML Timer 或 Python 运行时。
- FluentWinUI3 播放/日志/设置页，三种导航宽度、窄屏设置重排、统一字阶、系统/浅/深主题。系统中文字体回退，不携带商业字体。
- 版本化 JSON、字段校验、QSaveFile 原子保存、数值输入 200 ms 合并、保存失败重试、损坏文件覆盖前备份；手动只读导入旧 INI。
- 有界日志模型及跨线程队列、过滤/清空/导出、2 MiB 单备份轮转、文件写入失败反馈。
- 透明覆盖窗、输入穿透/不激活/置顶标志、显示器选择、可选前台限制、调试信息及 CPU/内存/调度间隔统计。
- 项目内工具/缓存/数据路径规则保持；移除旧单条 PreviewDriver。历史 Python 和计划归档不参与编译且内容未改。

## 短时性能记录

环境：Release、Qt 6.11.0，AMD Ryzen 5 5600（12 逻辑处理器），机器安装 RTX 4070 及虚拟显示适配器；本轮未直接采集实际 RHI 设备或 GPU 利用率。覆盖窗 2560×1440 逻辑像素、DPR 1、系统报告 165 Hz。控制窗同时可见。独立中文/英文混合文字，24 px、1 px 描边；允许重叠以确保指定负载；每轮 4 秒，含冷启动，没有长期热稳定预热。

| 在屏数 | GUI tick P95 / P99 | 采样末工作集 | 采样末 CPU（整机归一化） | 呈现回调累计 |
|---|---|---|---|---|
| 500 | 16.90 / 17.25 ms | 228.1 MiB | 3.9% | 250 |
| 2000 | 40.98 / 61.41 ms | 355.5 MiB | 11.0% | 112 |

两轮均无引擎丢弃，活动数为 500/2000，缓存各 500/2000 项。数据来自 `out/validation/20261007-040259-405/bench-*.json`。该批次旧 `updatesPerSecond` 字段按固定一秒估算，终场不足一秒的值不可用于比较；后续已改为按实际采样时长归一化。本表不引用该字段。

P95/P99 是 GUI 定时器间隔，呈现回调不是显示器光学测量，不能当作 GPU 帧时长或同步误差。2000 条明显达不到稳定 60 FPS；默认 500 为容量上限，不承诺任意字体、描边与分辨率下的帧率。没有本轮 Python 对照，不宣称已量化提速比例。

## 已实现但仍待实机验收

- 真正点击穿透、透明合成观感、焦点切换、独占全屏、跨显示器与混合 DPI；目前只验证标志和截图。
- Windows 高对比度/文本大小变化、Narrator、完整键盘流程、官方控件减少动画行为；不能宣称全面 WinUI 无障碍达标。
- PotPlayer 等不同播放器的实际暂停/跳转/倍速及同步误差；当前实机证据仅为 Chrome 播放中的读取，其他场景使用注入测试。
- 1080p/4K、GPU 时间/显存、长时间压力、休眠恢复、会话服务失效恢复；SMTC 初始化失败会显示错误，需重启应用重试。
- 无开发环境的干净 Windows 机器和公开发行材料；本机清除 SDK 路径试运行不能替代干净机。部署仍需要官方 VC++ x64 运行库。

不支持高级脚本/定位弹幕、跟随播放器窗口裁剪或全屏注入。媒体身份依靠 SMTC 提供的标题/作者/时长，信息相同的切换可能无法识别。前台关联失败时关闭“仅播放器在前台显示”。
