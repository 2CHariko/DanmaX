## 设置更新保留在屏弹幕（2026-10-07）

原设置路径调用 `Engine::configure()`，内部跳转会清空活动对象和游标；不是 XML 重新解析。现在应用服务使用独立的 `reconfigure()` 更新配置，保留来源数据、投放游标、ID、滚动横坐标和已显示动画时间。初始化/演示重置仍使用 `configure()`，加载、真实跳转及媒体切换保留清空语义。

- 速度从后续推进使用新值；固定时长减去已显示动画时间，暂停墙钟不计入，缩短至已显示时间以下只让到期的固定弹幕退场。
- 容量变化按到达顺序迁移存活槽位，减少时保留较早在场对象、移除超额较新对象；不会因存活槽位编号较大而误删。未来投放、清空、跳转均可继续复用对象池。
- 字体/字号/描边/行距变化只重新测量当前在屏文字；优先保留原轨道编号，固定弹幕重新居中/贴近对应边缘，滚动横坐标不重置。轨道数或视口变化、关闭重叠时按实际矩形和间距局部换轨；关闭重叠且无可用空间、文字超出可用高度时才移除对象。开启重叠时允许有界回退。
- 不透明度不触发核心重配置；纯速度/容量等修改不重建文字布局。字体变化清理布局缓存；描边/行距保留字形布局，重新计算外边界。需要的绘制资源仍在 Qt 同步/渲染阶段重建，不承诺字号修改零耗时或两个后端描边像素一致。
- 同一事件循环批次中的连续设置及窗口宽高通知合并为一次更新；暂停也主动呈现外观变化，不等待恢复播放。配置保存仍使用独立的 200ms 合并。新增 `retiredBySettings` 累计指标，和时间轴投放丢弃 `dropped` 分开。
