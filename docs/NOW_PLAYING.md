# 统一播放中心（初版）

侧栏第二项为“播放”。中间展示当前内容和元信息，整窗底部常驻横跨侧栏与内容区的全宽播放条，切换页面不结束播放。媒体库保留打开视频与最近播放列表，当前视频状态、选源和恢复操作集中在播放页。

## 操作

- “打开视频”或全局拖入视频：验证并使用默认播放器打开，进入播放页。
- “打开弹幕”：明确选择 XML 并独立播放；载入失败保留正在播放的视频。
- “连接播放器”：展开来源与播放方式设置，选择绑定会话和弹幕后点击“播放所选弹幕”。准备来源、修改绑定偏好不会抢占当前视频；确认播放才交接。
- 底部“播放／暂停”：独立模式控制弹幕时钟；外部模式控制播放器。首次开始跟随已连接的暂停媒体，会在新代次采样再次确认同一内容后请求继续；会话不可用时等待连接。不支持控制的按钮禁用。
- “弹幕”：显示／隐藏、更换 XML、搜索、缓存来源及卸载。隐藏只改变显示；卸载视频的弹幕保留视频连接和播放状态。
- “选集”：当前只支持已有番剧元信息的弹幕分集选择；独立来源播放中选择分集可重新开始，取消弹窗撤销待开始意图。视频文件与剧集列表尚未映射，视频选集暂不启用。
- “播放器”：视频任务显示当前播放器并可进入外部播放器设置，也可准备跟随其他播放器的新弹幕任务。
- “更多”：打开文件和结束本次播放。结束释放当前弹幕任务与控制事务，不主动关闭外部视频；已准备弹幕可再次播放。

播放／暂停及 VLC 定位均验证内容、会话代次、采样新鲜度，并等待控制确认和状态读回；不会乐观切换按钮状态。迟到结果不能接管新任务。独立模式和受控 VLC 支持拖动进度；PotPlayer 暂保持只读进度，精确续播限制见验收记录。

## 信息归属

独立弹幕展示标题、分集、来源和数量。视频优先展示已确认的番剧封面、名称及集名；未识别时显示文件名和统一 Fluent 图标。更换弹幕不会重写视频名称／封面。番剧信息以独立 `content` 字段保存到最近播放记录，XML 来源另行保存；视频指纹变化同时使进度、来源和番剧信息失效。

`NowPlayingModel` 是播放页面与底部条的统一界面入口，复用 `DanmakuSession`、`MediaSession` 和 `PlaybackCoordinator`，不增加引擎、覆盖层或帧驱动。媒体的播放状态与弹幕是否载入分开计算，避免卸载弹幕后把仍播放的视频显示为停止。播放器能力由真实后端提供，视频仍由外部播放器显示。

首版复用可展开来源设置；未增加视频解码、目录扫描、视频剧集映射或下一集队列。真实验收与未验证边界见 [FRAMEWORK_STATUS.md](FRAMEWORK_STATUS.md)。
