# 播放中心

侧栏“播放”与全宽底部播放条展示当前任务；切换页面不结束播放。支持视频同步和独立弹幕两种互斥任务，共用唯一引擎、帧驱动及覆盖层。

## 操作入口

- “打开视频”或全局拖入本地视频：验证文件和默认播放器，建立本次连接，确认视频并恢复进度，再准备弹幕。
- “更多 → 独立播放弹幕 XML”：无需播放器，从零启动独立弹幕时钟。先解析成功再交接；取消、文件损坏或无有效弹幕时保留当前播放。
- “弹幕”菜单：显示／隐藏、加载／更换 XML、搜索、缓存及卸载，均作用于当前任务。视频任务额外提供重新匹配；独立任务不识别播放器文件名。
- “播放器”菜单仅在视频流程提供预设设置。
- “更多 → 结束播放”及悬浮工具栏停止：结束当前任务。拥有 PotPlayer 时请求本次实例正常关闭；独立任务仅关闭弹幕层。

没有任务时，不通过搜索或缓存动作隐式启动独立播放；先明确打开视频或独立 XML。外部会话连接、手填应用 ID、旧播放方式配置和全局自动匹配开关继续移除。

## 控制与切换

视频播放／暂停及定位验证实例、内容、代次与采样新鲜度，并等待请求完成和读回；独立任务由本地单调时钟驱动，底栏和悬浮工具栏控制其暂停、继续与拖动，无媒体采样依赖。

独立任务更换 XML／在线／缓存来源时保留旧播放，成功后保留进度与暂停状态，位置按新时长夹取。新建独立任务从零播放。卸载保留独立任务的选源能力，载入新来源后可继续；结束任务则关闭并清空本次状态。

搜索、缓存与文件选择绑定打开时的任务，结束／切换后失效；晚到的加载、下载、控制或旧播放器退出通知不能影响新任务。独立任务加载失败不暂停或关闭当前视频。

应用拥有的 PotPlayer 在视频任务结束／切换到独立任务／应用退出时正常关闭，播放器自行退出也结束对应弹幕层；不接管原有实例、不强杀。VLC 保留现有非拥有语义。

## 数据与边界

视频元信息与弹幕来源分别保存，更换弹幕不重写视频名称／封面；独立任务展示自身 XML 文件名或在线番剧信息，不写入视频最近记录。XML 路径、缓存、最近播放、主题及样式保留，启动不自动播放。

DanmakuSession 管理独立来源的准备、加载与取消，MediaSession 管理视频、自动匹配、恢复及其来源；NowPlayingModel 按所有者投影状态与能力。内部合成时钟测试端口保持不可由产品 QML 调用。

PotPlayer 完整路径、播放器报告倍速及同名同长度切换仍有协议限制；验证范围见 [验收记录](FRAMEWORK_STATUS.md)。
