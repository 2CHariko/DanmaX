# DanmaX 应用图标

直接替换本目录的 `icon.png`，保留文件名即可。当前蓝底白色 X 是可自由替换的占位图。

- 建议使用 512×512 或更大的正方形 PNG；支持透明通道。
- 构建自动保留比例缩放，非正方形居中留透明边，不拉伸、不裁切内容。
- 自动施加边长 20% 半径的圆角透明遮罩，并超采样平滑边缘；四角不要放重要内容。无需自行加圆角。
- 自动输出 16、20、24、32、40、48、64、128、256 像素的 32 位 PNG 帧 ICO，嵌入 Windows EXE；同源圆角 PNG 用作 Qt 窗口图标。
- 替换后运行正常构建或打包命令即可更新，无需手工转换。输出在对应构建目录的 `branding/`，不覆盖源图。

只预览生成结果（从项目根执行）：

```powershell
./scripts/generate-icon.ps1 -OutputDirectory "$PWD/out/icon-preview"
```

生成器使用 Windows 自带的 Windows PowerShell / System.Drawing，无下载或新增第三方库。CMake 使用系统目录中的明确路径调用。每次构建检查源图、生成脚本和输出文件的 SHA-256；即使替换图片保留了旧修改时间，也会重新生成。内容无变化则保留输出时间戳，不重复编译图标或链接 EXE。缺失、损坏的输出或状态文件会自动重建。
